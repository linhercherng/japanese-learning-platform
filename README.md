# 日語學習平台

以繁體中文協助學習者從零開始，逐步掌握五十音、發音、書寫、日常生活日語，並準備 JLPT N5、N4、N3。

目前階段：**規劃提案與第一版手機樣稿，2026 年 10 月 12 日**。此儲存庫存放完整產品規劃與可點選樣稿；正式應用程式、完整教材、語音與題庫尚未製作。

## 第一版手機畫面樣稿

以「容易學習、容易記憶」為重點，完成今日首頁、五十音、字形與筆順、手寫練習、生活課程與點餐單課，另有相似字複習示例。暫用「日和」作為樣稿名稱。

直接在瀏覽器開啟 [prototype/index.html](prototype/index.html) 可操作；[樣稿總覽](prototype/overview.html)與[六頁截圖](prototype/review-images/overview.png)方便比較畫面。GitHub 會顯示 HTML 原始碼，需下載後在本機開啟，或啟動本機靜態伺服器。

樣稿只提供操作示意，進度為範例，字跡與輸入重新整理即清除。音檔、正式評量及資料儲存尚未接入。詳見[樣稿說明](prototype/README.md)與[驗證紀錄](docs/mockup-review.md)。

## 學習路徑

| 階段 | 學習重點 | 學完能做什麼 |
| --- | --- | --- |
| 五十音入門 | 平假名、片假名、筆順、聽音辨字、發音節奏 | 看懂假名、寫出字形、分辨容易混淆的聲音 |
| 生活日語起步 | 招呼、自介、數字、時間、購物、點餐、交通 | 完成簡單生活任務，寫下個人資料與短句 |
| N5 基礎 | 基本助詞、動詞與形容詞、常用單字與漢字 | 理解簡短對話、告示與文章，寫簡單日記 |
| N4 進階 | 動詞活用、句子連接、經驗與計畫 | 說明需求、理解生活通知，寫留言與短訊 |
| N3 中級 | 複合句、語意辨析、篇章理解、自然速度聽解 | 說明理由與看法，閱讀較長文章，寫實用短文 |

每一階段同時保留「認識、聽、說、讀、寫」練習。檢定準備另設分級題型練習、計時模擬與弱點分析。JLPT 沒有會話或作文測驗，因此平台的口說與書寫成果另行呈現。[JLPT 官方 FAQ](https://www.jlpt.jp/sp/e/faq/)

## 建議產品方向

手機優先的網頁平台，後續加入 PWA 安裝及指定課程離線練習。首頁直接呈現「今天學什麼、該複習什麼、上次學到哪裡」，每天以 15～30 分鐘完成一個小循環。

主要功能包括五十音互動表、筆順與手寫板、音檔與錄音回放、生活主題課程、文法與漢字庫、個人複習清單、錯題本、書寫作品集及 N5～N3 檢定專區。

## 第一版建議

先製作可審閱的畫面樣稿，再交付五十音的學習循環：字卡 → 音檔 → 筆順 → 描寫 → 默寫 → 小測驗 → 隔日複習。

第一個可用版本涵蓋完整基本假名、基礎音韻、6 個生活主題及本機進度備份。後續分期補齊生活課程、N5、N4、N3、雲端同步及模擬測驗。自動發音評分與自由作文批改先做可行性驗證。
