# 日和｜日語學習平台

繁體中文、手機優先的日語學習平台，從五十音到生活日語，再循序練習 N5、N4、N3。每課先理解、聽讀，收起提示回想，最後寫自己的句子。

**第二版本機學習程式 v0.2.0，2026-10-13。** 已依使用者確認的畫面與「規劃完直接執行」指示實作。私人 GitHub 保存程式；尚無公開部署或雲端同步。`prototype/` 保留原樣稿，第一版可從版本歷史與原交付包回溯。

## 開始使用

已安裝 Node.js 22 以上時，執行 `npm run dev`，開啟 [本機日和](http://127.0.0.1:18089/)。Windows 可雙擊 `start-hiyori.cmd`，不需安裝 npm 執行依賴。到「課程」選程度，「練習」回想到期項目，「我的」保存備份與離線包。

若18089已占用，執行 `node scripts/serve.mjs 18091`。進度依瀏覽器及網址來源保存；換連接埠前先匯出 JSON，再於新來源合併匯入。

## 保存、複習與離線

- 每輪只記首次提交，提示使用跨刷新保存，不計為無提示成功；填空接受明示字形／讀音變體，排序用詞塊。
- 可依級別、能力抽最多10題，或練收藏詞卡；獨立模擬卷不混入這個題池。
- IndexedDB保存作品、草稿、進度、收藏、回想、模擬。第一版資料與備份可升級，原ID／作品保留；不同進行中模擬及分歧首答明示拒絕合併。
- 回想歷史最多100輪；先下載完整備份、確認已保存，再整理完成輪次。首次作答、作品、複習、未完成輪次保留，舊結果可合併備份恢復。
- 首次連線完成SW安裝後，文字與筆順可離線。K／生活／N5／N4／N3音檔包約1.9／6.8／33.5／56.4／80.0 MB，全檔SHA-256通過才標完成；失敗和取消保留既有完成包。
- 可用瀏覽器安裝功能加入桌面；iPhone可用Safari分享選單加入主畫面。仍需實機驗收；本機網址不能直接供另一支手機連線。

語音為 Microsoft Haruka Desktop（ja-JP）合成聲音；自編試用教材與音訊尚待獨立日語教師審校。文字與手寫採自評。使用者主動允許麥克風後可錄音回放，音訊僅留當次頁面，離開即釋放；不保存、上傳或自動評分。

## 開發與檢查

```sh
npm test
npm run build
npm run check
```

建置統一文字換行、重產離線包與shell雜湊、清理並輸出`dist/`。改內容或介面後先build再check。靜態版須透過HTTP開啟，不能用`file://`取代服務。

`?qa=1`使用獨立QA資料庫並略過SW；`?qa=1&offlineQa=1`可驗收離線。QA資料、個人作品／錄音／備份及憑證不得提交。本版49項測試和內容／素材／語法檢查通過；實際瀏覽器驗證單課、寫作、收藏、分科模擬、續作、備份，以及停止伺服器後離線播放。詳見[第二版驗證](docs/v2-validation.md)。
