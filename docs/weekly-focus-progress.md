# 七天重點完成與改善追蹤（v0.44.1）

2026-10-24。讓五十音、生活日語與N5～N2的每週重點有固定比較起點，清楚區分「練過」與「能跨日自己想起」，用少量練習照顧還沒記穩的地方。

## 使用流程

每週回顧 → 追蹤這組重點 → 首頁依到期與當前弱點練原題 → 回週報看完成／改善與下一步。保存時以今天起七個台北日期為期間，明示開始與結束日；它和上版動態「下一週建議」分開。查看首頁／週報不自動保存或製造歷史。過去未保存的建議不假裝已追蹤。

同時只有一組有效追蹤，這七天不因每天排序改變而換掉原題。5分鐘一個能力、一題；其他時間最多三能力，每能力三原題。完成一輪便休息；不要求每天做完所有項目、不自動升級程度。期滿可另存下一組，舊組保留；畫面顯示最新四組，完整記錄在備份。最多260組，不自動刪掉舊資料。

## 週報如何讀

- **已練原題**：追蹤之後、期間以內，有時間可核對且唯一的同原題同能力首答；不是完成一輪或熟練率。
- **弱點已改善**：起點尚未有可靠記憶證據，之後有可比較的跨日無提示成功，且期間末狀態仍可信。一次答對、提示後成功、同日訂正不算；再次錯答會回到仍需複習。
- **維持想起**：起點已有跨日／七日證據，期間再有新的可比較成功，和新增改善分開。
- **仍需複習**：目前期間末原首答仍錯或需要提示；**跨日待確認**：已練但尚無新的可靠跨日成功；**紀錄待確認**：時間碰撞、舊提示不足或起點原題缺失；**尚未練**另列。

每題的原課名與能力、狀態和下一步收在「逐項看改善與下一步」，摘要先呈現少量數字與一個入口。原題／答案／私人草稿不在預覽洩露。

歷史組最多分析到第七天台北23:59:59.999，之後成功不冒充當期完成。較晚匯入的早期提示仍可更正證據。答後回饋保持原成功證據，並重算之後間隔。這些是平台練習證據，不等於永久記住或檢定成績。

## 首頁如何調整

首頁以最新一組原目標「現在」的證據優先目前仍需／待確認的原題。期滿後仍可收尾；之後有可靠改善便解除弱點優先，不被歷史期間內的錯答永久綁住。下一組只替換推薦優先，舊紀錄不刪。

原七日／隔天／同日補強順序、目前狀態順位、1／3／7日間隔與最後曝光時間保持；同類同狀態內先追蹤題，再沿用近期提示／失敗排序。全域未完成活動先接續、當日完成便休息，每課／每字限制及5分鐘一題保持。五十音詞音沿原手動工具；其他能力在等待時不擋住已到期詞音，詞音入口也優先實際已到期的追蹤字，避免練剛參考過的別字。

## 資料與保存

schema3新增可選weeklyFocusPlans，沒有追蹤的舊資料不補空欄位。每組只保存id／建立時間／日期／份量與原題×能力＋baselineAt，不複製答案、總分或私人內容。起點和改善均需連回原始資料，報告唯讀重算。

保存追蹤在原交易內重算預覽key與台北日期；候選或午夜改變時先更新確認，不能默存另一組。保存失敗沿既有待存備份與重試流程；離頁不搶路由。備份嚴格驗證、同id不同內容或期間重疊拒絕，合併不覆寫首答、原輪、草稿或作品。

無新依賴、日文教材或音檔。獨立教師、真人長期效果與手機實機驗證仍須另有證據。
