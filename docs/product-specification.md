# 日語學習平台產品規格提案

版本 v0.1，2026 年 10 月 12 日。目標是讓繁體中文使用者從五十音開始，持續練習日語的理解與表達，最後具備準備 N3 的完整學習路徑。規格與第一版範圍待使用者審閱。

## 對象與設計假設

主要對象是日語零基礎或曾學過但容易遺忘的自學者；次要對象是已有基礎、希望依生活主題補強或準備檢定的人。

- 繁體中文介面與解說，日文例句可切換振假名。
- 手機優先，同時支援桌機與平板；手寫可用手指、滑鼠或觸控筆。
- 每天建議 15～30 分鐘，可調整成 5、15、30 分鐘的學習量。
- 私人專案起步；單一使用者可免登入試學，後續保留多人帳號的擴充空間。
- 初期以自編並經審校的教材為核心；AI 作為輔助工具。
- N5／N4／N3 為學習入口與教材難度標籤；課程能力不只用檢定分數衡量。

## 三種產品方向

| 方向 | 優點 | 代價 | 判斷 |
| --- | --- | --- | --- |
| 手機優先網頁，後續 PWA | 可快速審閱、同一套介面支援多裝置 | 錄音與離線儲存需逐瀏覽器驗證 | 建議採用 |
| iOS 與 Android 原生 App | 更深入整合裝置功能 | 開發、上架與維護範圍較大 | 待平台成熟再評估 |
| 單純檢定題庫 | 容易集中資源在考試練習 | 無法充分覆蓋五十音、發音與書寫 | 可作為平台的一個模組 |

## 核心使用情境

1. 零基礎學習者打開平台，選擇入門，從あ行開始，聽音、看筆順、描寫並完成小測。
2. 學習者準備去日本旅行，選擇餐廳主題，學會點餐，再寫出自己的訂位短訊。
3. 學習者常把シ與ツ混淆，在複習中心收到針對字形與聽音的辨識練習。
4. 考生選擇 N4，完成分科診斷，補強動詞活用與聽解，再做計時模擬。
5. 學習者換裝置後接續課程；此情境在雲端版本實作與驗收。

## 功能規格

| 模組 | 必要能力 | 完成條件提案 |
| --- | --- | --- |
| 入門與程度診斷 | 選擇零基礎、已有基礎、檢定目標與每日時間 | 可略過診斷、手動選課，不因答錯而封鎖學習 |
| 五十音 | 假名表、字卡、筆順、音檔、相似字辨識 | 每字可查、可聽、可練、可加入複習 |
| 書寫 | 描寫、提示減少、默寫、聽寫、句子輸入 | 可重寫與復原；保存作品與回饋，區分手寫和鍵盤輸入 |
| 發音 | 單音、單字、句子、跟讀、錄音回放 | 可比較示範與自己的錄音；無麥克風也可學習 |
| 生活課程 | 主題、能力目標、對話、單字、句型與實作 | 每課能完成一項可描述的生活任務 |
| 文法與漢字 | 用法、限制、易混淆點、讀音與常用詞 | 可由例句跳回課程；漢字標明日文字形與語境讀音 |
| 複習中心 | 到期複習、錯題、收藏、能力別熟練度 | 看懂與聽懂分開紀錄；復習超量可減少新課 |
| 檢定專區 | N5／N4／N3、題型練習、計時模擬、解析 | 題型及時限可版本化；結果標為平台練習成績 |
| 學習紀錄 | 進度、弱點、學習時間、作品集、備份 | 不把觀看教材等同掌握；可匯出與刪除個人資料 |
| 教材管理 | 草稿、審校、發布、版本、錯誤回報 | 未審校內容不進正式課；可回滾錯誤版本 |

## 能力與進度模型

以認字、聽辨、發音練習、閱讀理解、手寫、文字表達六個維度呈現成果。發音尚未經可靠自動評量時，只記錄「已跟讀／已錄音／已自評」，不顯示假精確的熟練分數。

單元狀態分為未開始、學習中、已完成練習、待複習、已達平台熟練門檻。完成影片或字卡只能推進「學習中」；必須有獨立作答及間隔複習證據，才能標示熟練。

檢定能力採文字語彙、文法、讀解、聽解分開分析；口說與書寫仍保留在生活能力頁。提示後答對與首次無提示答對分開計算。

## 版本邊界

| 第一個可用版本必備 | 後續逐步加入 |
| --- | --- |
| 基本平假名與片假名、基礎音韻 | 完整 20 類生活主題的分級內容 |
| 音檔、筆順、手寫、自評與小測 | N5／N4／N3 課程與模擬測驗 |
| 6 個生活主題 | 登入、跨裝置同步、課程離線包 |
| 到期複習、錯題、進度、本機備份 | 自動字形輔助、發音分析、短文輔助回饋 |

教師班級、公開社群、排行榜、付費訂閱及證書不是本次核心範圍。未來若需要，另立規格。

## 使用體驗與品質

- 平常課程可暫停續學；正式模擬模式以分區計時規則執行，另提供可暫停的練習模式。
- 手寫區與翻頁操作不互相搶手勢；主要按鈕單手可觸及，點擊區目標至少 44 × 44 CSS 像素。
- 正文支援放大、鍵盤操作與可讀對比；色彩不能成為唯一的對錯提示。
- 振假名、中文提示、羅馬字可獨立開關；羅馬字逐步退出主要練習。
- 日文文字區指定日文字體與語言，避免繁體中文字形混入手寫示範。
- 課程音檔播放失败可重試並顯示文字；檢定聽解中不直接揭露逐字稿。
- 同步狀態、離線狀態與保存結果有明確提示；刷新後不得靜默遺失已確認的答案。

| 編號 | 情境 | 可驗證結果 |
| --- | --- | --- |
| A01 | 新用戶開始五十音課 | 三次主要操作內進入第一個學習項目，無需先註冊 |
| A02 | 進入任一基本假名字卡 | 字形、讀音、筆順、練習入口完整，內容審校通過 |
| A03 | 完成一次手寫練習 | 描寫與默寫分別紀錄，清除、復原、重寫可用 |
| A04 | 拒絕麥克風權限 | 可繼續聽音、跟讀與自評，進度不被阻擋 |
| A05 | 把字看對但聽錯 | 聽辨弱點單獨加入複習，認字紀錄不被覆蓋 |
| A06 | 完成一課並刷新 | 已提交進度恢復；未提交草稿按版本規格恢復或明確提示 |
| A07 | 匯出再匯入備份 | 同一版本重建進度與作品；錯誤檔案拒絕匯入，原資料保留 |
| A08 | 生活主題測驗 | 對應能力目標，提供錯誤解析及一項文字輸出任務 |
| A09 | 雲端版跨裝置 | A 學習、B 顯示；B 更新、A 顯示；刷新與重新登入恢復，另測衝突 |
| A10 | 檢定模擬完成 | 每區時間正確、已提交答案保存、分析不冒稱官方成績或合格證明 |
| A11 | 教材版本更新 | 舊紀錄仍可查原版本，錯誤題可停用，複習不重複計分 |

## 工程規格待定項目

此階段為產品規劃，尚未選定套件版本、資料庫、部署服務或建立程式。技術候選、資料實體及測試方向見[版本與交付路線](roadmap.md)。

實作規格定稿時須補齊六項：目標與成功條件、可執行的開發／建置／測試指令、目錄結構、實際程式風格範例、測試策略、修改邊界。`npm run dev` 等指令目前不成立，README 不將其列為可用指令。

## 合作與修改邊界

- 每次發布附上內容版本、測試證據與已知限制。
- 規格與畫面審閱完成後，再實作對應功能；雲端、外部服務與新增費用另列具體方案。
- 原始音檔、教材來源與已發布版本保留，不以新版本直接覆蓋不可回溯的舊資料。
- 金鑰、私人錄音、手寫作品、個人作答紀錄不得放入 GitHub 儲存庫。

## 待確認的產品選擇

目前以個人自學、網頁優先、每日 15～30 分鐘及核心能力為預設。後續審閱可調整品牌名稱、是否需家人各自帳號、離線需求、真人錄音預算與是否指定某次考試；這些選擇不影響本次完整課程規劃。
