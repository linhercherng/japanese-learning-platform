v0.39.0，2026-10-23，Asia/Taipei。[執行計畫](plans/2026-10-23-unified-weekly-review.md)、[驗收](unified-weekly-validation.md)。

## 使用路線

首頁直接點「每週回顧」看近七日活動，或「記憶與弱點」看目前累積原題。六區為五十音／生活日語／N5／N4／N3／N2；各能力分開，單位統一原題×能力，而非整課完成率。原輪未完成先接原ID；無pending才依原每日建議與課程工具練習。

| 畫面 | 完成內容 | 可接續 |
| --- | --- | --- |
| weekly | 台北近七日學習天、每輪首答、每題每日首答、跨日及七日證據；六區累積摘要／能力 | 今日下一步、各區路線與弱點 |
| weaknesses | 學習區／記憶狀態篩選、12項分頁、原題ID／能力／最近首答與證據日期 | 原課少量原題／五十音原地圖；pending先接原輪 |
| 首頁 | 明顯回顧及弱點入口 | 原有今日單一步驟 |
| 舊工具 | 深化概念、文字修訂、備份後整理保留於原頁收折區 | 原操作與原稿 |

## 怎麼知道記住了

| 狀態 | 證據與解讀 |
| --- | --- |
| 需要再複習 | 最近首答或該日第一個答案錯誤／提示；同日後來答對不沖掉 |
| 紀錄待確認 | 同時間多筆無法確定順序，或舊五十音最後提示時間晚於原答、無法重建提示歷史 |
| 無提示答對，跨日待確認 | 有正確紀錄，尚無充分跨日比較 |
| 已有跨日記憶證據 | 原題×能力較早練過，當日第一筆無提示正確，距前次可見練習／線索至少一個台北日期 |
| 已有七日記憶證據 | 上述條件且至少七個台北日期；是跨日證據子集，不重複加總 |

沒有資料不推論不會；曾跨日想起不保證永遠記住。近期與累積兩種時間範圍明示。未來資料排除；重疊不任選成功；其他能力、比較字與訂正的可見曝光納入間隔。生活與檢定有逐日提示記錄，答後回饋影響下一次間隔，不抹除先前證據。五十音舊格式只有最後提示，無法完整還原者保守另列；不改舊首答補救。

手寫自評、作品與訂正另計，其他舊深化原題在原工具保留。新摘要不預覽題幹、選項、正解或私人線索；五十音字種＋原字表序號定位，原圖看字形；生活／檢定使用課名與原題ID。這次沒有新增日語教材／音訊或官方能力宣稱。

## 技術與資料保留

unifiedReview是純計算，使用原attempts、提示及比較／訂正紀錄。unifiedLearning保護pending與原下一步；沒有新增schema、偏好、帳號、後端或聚合分數。篩選與頁碼在hash，重開可找回，不寫入學習庫。所有metadata編碼；原文字作品僅在主動展開原工具後由既有功能查看。

本週範圍是最近七個台北日期截至現在，沒有選擇更早週期的額外介面。自評與不同能力不互相替代，平台結果不能推論JLPT合格率、自由口說／手寫能力或真人長期效果。回退程式前先匯出備份，保留所有新舊資料。
