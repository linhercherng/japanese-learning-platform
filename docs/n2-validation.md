# N2 首批 v0.4.0 驗收

日期：2026-10-14。範圍為N2第一批原創公開試用教材及平台整合，並非官方完整必考清單；獨立教師審校、真人聽音及實機iOS／Android仍未驗收。

## 教材

- 24主課、288課內詞條（180個不同詞形／讀音）、48個文法、72漢字位置（71個本級字）。
- 24篇503～581字閱讀、144句對話、240課後／讀解題、24寫作參考（223～252字）。
- 20分類各一個N2情境，各8詞、6句對話、5題及150～250字寫作任務；100題。
- 400條補充詞彙；目錄合併後N2共543個詞形／讀音組合，含生活擴充／銜接詞。
- 兩套獨立原創模擬卷，各70題，語言知識・讀解50題／105分鐘，聽解20題／50分鐘；短練15＋5題、各區5分鐘。題數與原始答對率是平台編排，不換算JLPT尺度分數。
- 8個N2概念、24個變式回想；文法、聽辨、自行運用分開記。
- 全站114主課、80情境、12生活起步、8卷、3422詞、360漢字、228主課文法及2136固定自編題；208假名卡／740題保持原有覆蓋。

## 程式與素材

- 兩／三考區相容；短練選題快照、時限續考、首答不覆寫、匯入完整題目／時間驗證、N2目標及每日安排備份回復測試。
- 新增14例句音檔補齊每日概念卡；生成／離線索引均收concept.example及回想逐字稿，缺8個N2例句的測試能失敗。
- N2可選包1999檔，63517996 bytes（60.6 MiB），缺檔0；全包逐檔SHA-256，SW支援N2及Range播放。
- 音檔索引10717，新增1177個MP3均以ffmpeg完整解碼，失敗0。舊9540個索引路徑與10465份已追蹤音訊／SVG原檔未改。
- 筆順SVG508份，固定KanjiVG commit 70a0b7ae0c18ceb5cb358274b029cce0234a43bc，保留原始bytes及CC BY-SA 3.0。
- 規格／教材一致性審查先完成，修正詞義轉換、備份用語及三篇寫作字數；程式審查另修N2每日／弱項課程連結與概念音檔。兩階段複查通過。
