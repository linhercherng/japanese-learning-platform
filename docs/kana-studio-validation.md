## 交付範圍

- #kana-studio 練習工坊可選208卡，基本字、濁音、半濁音、拗音與兩套字形皆可進入。
- #kana-fade：完整聯想圖與範字 → 聯想輪廓 → 第一筆前25% → 只聽聲音。16種原創SVG輪廓與標記套用208卡；聯想不是字源。後三階導覽／標題不顯示答案。顯示提示即記錄當日曝光，不能切到第四階洗掉提示歷史。
- #kana-dictation：獨立KS草稿、無範字畫板、鎖定原跡、疊圖／分開對照、字形與筆順自評。鎖定前看提示會保留；鎖定後不可修改原稿；重複保存不覆寫首答。原描寫草稿獨立保留。畫面提醒平／片種類與同音限制，不宣稱自動手寫辨識。
- #kana-words：每字最多3個不同詞例，190卡共514個詞中回想題，154卡有3例。題目遮住目標的所有出現位置，沿用V3首次答案、提示、訂正、續作與結果。
- 18卡沒有收錄自然片假名生活詞（ヲ、ヂ、ヅ、キョ、ニャ、ニョ、ヒャ、ヒュ、ヒョ、ミャ、ミョ、リャ、リョ、ギョ、ビャ、ビョ、ピャ、ピョ），明示並提供有詞例的平假名對照，不把人工片假名轉寫當自然用詞。這是目前詞庫覆蓋範圍，不代表日語不存在這些用法。
- 新增32補充生活詞及32個Haruka合成音；不標定JLPT必考級別。既有詞庫仍3441詞、主課114、情境80、生活12、模擬8、假名加練740題，這批詞例題另外計算。

## 資料與離線

- 沿用schema3；v3.kanaHints可選，舊備份不需補欄位。新草稿write:KS-字卡ID有嚴格metadata驗證；描寫與默寫互不覆蓋。
- 兩份未完成默寫任務不同時明示拒絕；同任務鎖定原稿優先，提示取聯集。完成首答與提示或作品原跡衝突則拒絕合併，保留原備份，不改寫答案。
- 儲存交易失敗仍保留待存狀態及快取的鎖定／提示metadata，可從現有備份功能完整匯出。沒有重設資料庫或上傳個人作品。
- 新來源kana-words有穩定kw題目ID與來源一致性驗證。題目由完整詞庫解析，不依當前前三詞排序，避免選詞排序影響歷史。
- 86份離線shell；K包658個MP3、約3.2MiB，所需詞音無缺檔。10,915個既有音檔映射全部保留，總索引10,947；新增32檔全部以ffmpeg解碼通過。其他音檔包保持完整。
