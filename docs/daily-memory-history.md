# 每日推薦採用完整提示與記憶歷史

v0.42.0，2026-10-24，Asia/Taipei。[執行計畫](plans/2026-10-24-daily-memory-history.md)、[驗收紀錄](daily-memory-validation.md)。

## 今天只需要想起一小步

首頁同時讀取五十音、生活日語與 N5／N4／N3／N2 六區的原始作答及完整提示時間線，推薦一條路線。原考試、未完成原輪與已開始每日安排先接續；今天完整完成一輪後可以休息，不要求把六區做完。

| 目前證據 | 自動推薦的間隔 |
| --- | --- |
| 單次無提示答對，尚無跨日證據 | 最後曝光的隔天 |
| 需要提示、答錯或紀錄待確認 | 最後曝光的隔天；當日仍可少量弱點補強 |
| 已有跨日記憶證據 | 最後曝光後三個台北日期 |
| 已有七日記憶證據 | 最後曝光後七個台北日期 |

「最後曝光」包含作答、答前提示、答後回饋、參考、舊時間紀錄，以及已保存的五十音對照與訂正曝光。1／3／7 是本平台的保守複習安排，並非個人記憶時效或檢定能力保證。

## 提示階段如何影響推薦

- **答前提示：** 當次或當日先看線索，不能冒充獨立回想。合併備份帶回較早線索，也會更新分析，但不改原答案的 hinted 值。
- **答後回饋：** 保留作答當下已成立的跨日或七日證據；從這次回饋重新計算下次間隔。不能倒灌成原作答用了提示。
- **後續參考：** 視為重新接觸原內容，等待適當間隔後再自查；只有看參考而沒作答，不創造練習題。
- **舊階段不明／同時答案：** 原首答保持，標示待確認，優先用另一次清楚的原題回想補證據。
- **同日先錯後對：** 保留當日第一個答案所反映的弱點，不由訂正成功宣稱已記住。

首頁與週報共用 `memoryEvidence`，未來事件、手寫自評、作品、獨立詞庫與模擬考不混入客觀原題記憶證據。

## 少量原題與明確原因

全區先七日、再到期間隔回想、再同日弱點；同類先需要再複習，其次紀錄待確認，再看明確選的目標與較早練習。每輪最多三題，5 分鐘一題。五十音只自動選認字與聽辨，同字只取一種能力；生活與檢定每課只取一題。詞音拼寫仍可從原練習與弱點頁查看。

`#today-review/K:week` 等確認頁只列原課、能力與記憶狀態，不展示題幹、答案、音檔或私人草稿。按「收起線索，開始回想」才建立既有 source/reference 的 V3 原輪，不另建總排程。原工具仍可自行加練；自動到期與手動練習分開。

首頁的「這個建議的記憶依據」說明五種記憶狀態、答前提示／答後回饋／參考／舊階段次數、下次日期，連回原時間線與弱點。這些次數是可見歷史，與正確率及熟練度分開。

## 保存與時間異常

沿用 schema3，不新增持久欄位、不改題庫。推薦、預覽、重新整理、篩選與週報全部唯讀；原進度、首答、草稿、作品、未完成原輪、提示側錄與備份保持。開始時在保存交易內重算，保護期間出現的原輪；日期已變或題目未到期就不建立。

若同日原輪已存在，但更新、答案或完成時間晚於裝置現在時間，首頁提示先確認日期並回到原輪，停止另建同日輪次。完整建立於未來的輪仍不算今日已練。延遲保存時離頁或離頁再回相同網址，不搶走新路由；保存失敗仍保留候選資料、備份與重試。

本輪只整合既有原創試用教材。沒有新日文／音訊／依賴／後端／雲端資料；教師審校、真實手機與長期學習成效仍需外部驗證。舊版不認識新提示側錄時，應先備份並使用新版匯入，回退不可清除本機資料。
