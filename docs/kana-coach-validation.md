# 五十音記憶教練第一批驗證

2026-10-21，v0.5.0。使用者授權記憶地圖、混淆字專練、隔天檢查，測試後公開發布。

## 功能

- `#kana-map`：208卡的認字、聽辨、手寫自評分開顯示，可篩字形、分類、能力與待複習／未練習。點字可看紀錄、訣竅、筆順、少量練習與遮字默寫。
- `#kana-confusions`：用實際首答選項產生字組，雙向配對、聽辨、詞中補字，每組最多6題。同音字不互當聽辨唯一錯誤選項。沒有個人混淆時另提供既有教材比較入口。
- `#kana-check`：依台北日期，每日最多建立一輪、最多10個字與能力的檢查。只選較早日期已學過、今天尚未作答的認字／聽辨。支援未完成續作、結果及近5輪回顧。
- 首頁、五十音與記憶加練都有入口，延續目前位置與返回導覽。練習導覽以通用名稱呈現，不顯示目標字或字組。

## 證據與資料邊界

- 認字／聽辨每個日期只取首次答案；同日重做不增加獨立首答天數。當日首答錯誤或用過提示，同日再答對仍提示需複習。
- 「已有跨日回想」表示至少兩個日期的無提示首答成功；不表示正式熟練判定。手寫只記作品與自評。
- 隔天檢查若中途去別的入口先練同一能力，後續結果會排除該題的跨日首答資格，明示排除數量。
- 混淆依答案字形歸屬：如「ぬ換片假名」誤選メ，記為ヌ／メ。無實際選項的歷史錯誤不猜字組。
- schema與備份版本沿用3；attempt可選欄位 `kanaConfusion={target,chosen}` 有驗證。新事件隨作答永久保留，整理舊輪次也不抹去。舊輪次若有可辨識選項，可重建歷史混淆並去重。
- 新來源 `kana-map`、`kana-confusion`、`kana-check` 使用既有V3輪次，穩定題目ID可解析且有來源／題目一致性驗證。
- 兩台裝置各自建立同日檢查，合併遇到不同輪次會提示衝突、保留備份；不靜默覆蓋首答或把兩輪當成同一輪。

## 已執行驗證

- `npm test`：186/186通過，包含17個本批核心、視圖及控制器整合測試。
- 覆蓋208卡、能力獨立、首次答案、提示、同日訂正、台北午夜、未來日期、每日限一輪、10題上限、同音字、實際選項歸屬、持久化與去重、備份／合併衝突、練習導覽遮字。
- Node整合流程：地圖作答選錯 → 產生混淆組 → 完成6題專練 → 中途備份還原 → 下一日期開始隔天檢查 → 提示與答案保存、續作。
- `npm run build`、`npm run check`：通過。79個shell檔案，4個新模組已納入離線殼。
- 本機HTTP：79/79檔案逐一SHA-256及JavaScript MIME檢查通過。
- `npm audit --omit=dev`：0 vulnerabilities。
- 獨立核心證據與介面整合審查：均無Critical／Important；追加修改後相關17項測試覆核通過。
- 音檔與筆順沿用既有素材；208卡、508筆順、10,915音訊索引檢查通過。
