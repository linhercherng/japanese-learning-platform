## 各級題型覆蓋

題型庫使用漢字讀音、表記、語境選詞、近義表達、文法形式、句子組合、篇章文法、短篇與中篇理解、資訊檢索、課題理解、重點理解、語句表達、即時應答等標籤。N4／N3 加入詞語用法，N3 另有長文與整體理解；以官方題型表逐級核對，不將高級題型全部套用到 N5。[JLPT 題型表](https://www.jlpt.jp/e/guideline/testsections.html)

試卷組卷比例與題數尚未定稿。開發前建立逐級題型矩陣與試卷版本，不宣稱官方永久固定題數。

## 生活課程的編排依據

生活課以具體能力目標安排，例如點餐、問路與寫留言。日本國際交流基金 Irodori 採 Can-do 與生活情境，適合參照其能力目標的設計方式；不將其等級直接當作 JLPT 級別。[Irodori 教材介紹](https://www.irodori.jpf.go.jp/en/about.html)

平台對話、例句、插圖與練習以自編為原則。參考教材可作外部延伸閱讀，匯入或改編內容須逐資產確認授權。Irodori 免費下載並不代表可任意改編、重新散布或用於新平台。[Irodori 著作權與使用規範](https://www.irodori.jpf.go.jp/en/privacy.html)

## 教材工作流程

課綱與能力目標 → 自編初稿 → 日語審校 → 字形與讀音核對 → 錄音／筆順製作 → 題目與答案審校 → 手機預覽 → 發布 → 回報與修正。

AI 可協助生成候選例句、題目或翻譯，但必須經日語審校才能成為正式教材。審校者要確認自然度、程度、用語、中文解說、干擾選項及自由答案的合理範圍。

每道封閉題應有清楚的最佳答案，不能出現多個同樣合理的選項卻只接受一個。自由文字題以語意與任務為主，不採整句字串完全相等的判定。

音檔檢查讀音、重音、語調、音量、雜音與題目對應；慢速音檔不得扭曲音高。筆順與手寫示範以日語教學方式核對，避免使用繁體中文漢字筆順替代。

## 題庫與試卷管理

- 題目狀態為草稿、待審、可用、停用，停用題保留歷史與原因。
- 至少區分日常練習題與模擬卷保留題，記錄使用者是否見過。
- 每套試卷有題型矩陣、音檔播放腳本、時限、答案、解析與版本。
- 題庫以自編或明確授權為原則；官方樣題先提供外部連結，不直接複製至平台。官方試題著作權說明見 [JLPT FAQ](https://www.jlpt.jp/sp/e/faq/)。
- 內容錯誤修正後以新版本發布；受影響紀錄註記，複習與統計可按修正規則更新。

## 第一版教材交付清單

1. K01～K18 的教材目標、字卡、習題、音檔與筆順；基本平片假名各 46 字完整核對。
2. L01、L02、L04、L07、L08、L09 六個生活主題，各有對話、單字、句型、聽读、文字輸出與解析。
3. 針對ぬ／め、れ／ね、シ／ツ、ソ／ン的相似字練習。
4. 長音、促音、拗音與濁音的聽辨及跟讀素材。
5. 每項素材的作者、審校、版本與授權紀錄；未具備必要資料不得發布。
