# 首頁每日學習與複習完整整合

v0.38.0，2026-10-23，Asia/Taipei。[執行計畫](plans/2026-10-23-unified-daily-route.md)、[驗收與發布](unified-daily-validation.md)。

## 今天只決定一小步

首頁現在串起五十音、生活日語與N5／N4／N3／N2六個學習區。開啟首頁不會建立排程、題目、作答或提示曝光；主卡只推薦一條原有路線，寫出原因、原練習紀錄與台北日期。你仍可明確選目標與5／15／30分鐘，不會因一輪答對自動升級。

| 優先 | 今天的狀態 | 首頁行為 |
| --- | --- | --- |
| 1 | 模擬考進行中 | 回原模擬，計時與答案保持 |
| 2 | 目前分頁V1五十音、V2課內或V3任一原輪尚未完成 | 接原ID／原題；同類原輪最近更新優先，其他待接續活動可展開 |
| 3 | 五十音聽音默寫未評完，或舊每日安排已開始 | 接原字跡／原活動；自評與客觀首答分開 |
| 4 | 今天已完整完成一輪或每日安排 | 可以先休息，回看原結果；不要求把六區都做完 |
| 5 | 有符合日期的原題 | 七日→隔天→弱點→口袋；各區保留原資格、提示與題量 |
| 6 | 目前沒有需要先複習的內容 | 依明確選的目標，進原區少量新內容 |

同類複習優先目前目標；其餘以該區較早練習與固定區序決定。不是把相同題目複製成新總排程。練過數與最近日期是可靠原字卡／原題的歷史，不是檢定分數、跨日熟練或合格率。

## 首頁畫面

- **一個主建議：** 哪個區、做什麼、為什麼先做、進入哪個原頁。當日完成可以收尾。
- **六區進度（收折）：** 每區實際練過的字／原題數、最近日期、原區今日路線。沒有紀錄便如實顯示。
- **其他待接續活動（按需）：** 原ID與活動保持，不丟棄其他練習。
- **原每日安排（保留）：** 建立但未開始的安排是可選；已開始才優先接續。原四步理解→回想→運用→書寫與原工具入口仍可展開。
- **更新今天的推薦：** 只重算畫面；跨日後或返回首頁會依現在日期重新決定，不偽造新一天的學習證據。
- **完成後回首頁：** V2／V3結果與舊五十音完成頁可接回統一路線，原結果與原課輸出連結保持。

## 保存與公平性

沿用schema3、v3.goal、dailyMinutes及既有首答／提示／草稿／作品／備份，沒有新增持久欄位或新作答source。統計排除未來資料；實際未完成原輪即使裝置時間倒退仍須接續，避免另建一份。

V1完整原輪的今日收尾要逐題匹配已保存的事件ID、字卡／能力、正確與提示值，最後保存日必須是今天；只有畫面index或自評不算。V2歷史輪從既有練習中心找回結果。七日、隔天、弱點與原區規則一致，不把新題冒充跨日確認。

舊建立／加學按鈕也會在保存交易內檢查待完成原輪；延遲保存期間離頁、離頁又回同網址或控制器結束，仍保留已保存安排，舊操作不再搶走路由。失敗保留候選資料與可匯出備份，不清庫、不改原首答。

## 交付邊界
