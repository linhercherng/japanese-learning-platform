# 日和五十音學習與記憶強化完整規劃

## 2026-10-21 個人記憶教練第一批

原階段C由記憶地圖、實際混淆字專練、隔天檢查開始交付。三種能力分開呈現、首答與提示分開保存；新混淆事件保存在attempts，舊備份可正常讀取。詳細規則見[設計](plans/2026-10-21-kana-coach.md)及[驗證紀錄](kana-coach-validation.md)。以下保留各歷史批次原規劃。

日期：2026-10-14。適用：既有日和日語學習平台。核心目標：讓初學者能認出字、聽出聲音、寫出字，並在隔天仍能回想；不以做題量取代記憶證據。

## v0.3.2 延伸交付

使用者確認本規劃並要求補完整濁音、半濁音及拗音，新增116張記憶卡（濁音40、半濁音10、拗音66）與464道題（既有三種題型348題＋組字與拍數116題）。至此既有208卡皆有個別原創字形／組字提示，共740道加練題。分類、逐組或分類混合、平片切換、續作、首答與提示紀錄延續。

基本字舊題的ID、答案與選項顺序不改；舊all範圍仍只指基本46字。拗音一组3字時維持3題。じ／ぢ、ず／づ的同音選項不互當聽辨錯誤答案；詞形辨認提供詞例，重複字組的詞將每一處目標遮住。常用片假名詞、練習用轉寫及少見詞用途有不同註記。盲寫隱藏構成式、範字與詞形。

以下保留v0.3.1原規劃，原階段B的既有字卡強化已在本批實作；更多跨詞遷移、混淆追蹤與教師／實機審校仍為後續。範圍與驗收見[進階加練驗收](kana-advanced-validation.md)，本批不表示全部V3.1課綱深化完成。

## 1. 學習範圍與順序

|階段|內容|主要任務|進入下一階段的參考|
|---|---|---|---|
|起步|あ・い・う・え・お，認識日語的一拍|聽音、指字、看筆順、遮字寫|打亂順序仍能配對五個聲音與字形|
|平假名|46基本字，按10組行別少量學|每次3～5字；詞例聯結、聽辨、默寫|能在不同順序回想，容易混淆的字另列複習|
|片假名|46基本字，和同音平假名配對|平片雙向辨認、常見詞音與字形|不只背表格位置，看到陌生順序仍可辨認|
|聲音標記|清音、濁音、半濁音，共50張既有字卡|か／が、は／ば／ぱ等成組比較|能分辨聲音和右上標記；同音字用詞形辨識|
|小字與節奏|拗音66張既有組合卡；促音、長音、撥音|一拍／兩拍比較，詞語聽辨與書寫|不把小っ讀成つ，不把小ゃ讀成大や|
|綜合|相似字與日常詞|跨行、跨字形、聽詞補字、遮提示書寫|跨日首次回想與新詞情境逐步較穩定|

全平台延續208張假名字卡與18單元。這次新增的個別聯想集中於92個基本平／片假名；濁音和拗音仍以既有組字規則和音韻課銜接，不宣稱已為208卡都寫完個別聯想。

建議行別：あ→か→さ→た→な→は→ま→や→ら→わ・を・ん。每組完成後混入少量舊字，避免只背固定表格。學習者可自行跳行；不以固定日數承諾學會。

## 2. 每個字的記憶卡

每張卡提供：字形、同音另一套字形、原創字形聯想、可播放單字、詞義、正式筆順、遮字手寫入口，以及認字／聽辨／詞中運用的個別紀錄。

訣竅分為三種線索：輪廓（像什麼）、差異（多一橫／小圈／方向）、詞例（聲音放回完整詞）。避免用中文諧音判斷日語發音；羅馬字僅作輔助，可關閉。

|字或字組|提示示例|接著怎麼驗證|
|---|---|---|
|あ|中間交叉想成雨傘柄，外面曲線想成傘面，配あめ|聽あめ，遮住字再寫第一個字|
|い|兩筆想成一對小狗耳朵，左長右短，配いぬ|打亂い與其他母音，再聽音選字|
|ぬ／め|ぬ右下有小圈，め沒有|先比較，再遮住聽詞與默寫|
|は／ほ|右側一橫／兩橫|遮字後分別寫，再檢查橫筆數|
|シ／ツ|短筆方向與位置、長筆起筆方向一起比較|先看筆順，再聽音與回想字形|
|る／ろ|收尾有沒有小圈|兩字交換順序，不靠原字表位置|

聯想是自編記憶工具，不是字源，也不是標準筆順的替代。學習者選一個自己記得住的聯想即可，不必背整段文字。自編教材與合成音檔仍待獨立教師審校。

## 3. 練習設計

|練習|實際操作|能力記錄|本次範圍|
|---|---|---|---|
|聽音選字|先播單字音，選對應假名，正常／慢速可選|聽辨|92基本字各一題|
|平片配對|看平假名選片假名，反向也有|字形辨認|92基本字各一題|
|詞中補字|看詞義及缺字詞形，可聽完整詞，自己輸入缺字|詞中運用|92基本字各一題|
|描寫→默寫|看筆順、描一次，隱藏範字後寫；完成後才對照|書寫作品與自評|重用既有208卡筆順與畫板|
|相似字比較|並排比較、聽音、遮住兩字與詞例、連到默寫|按能力分開|既有6組並整合新入口|
|音韻小課|濁音、拗音、促音、長音、撥音、相似字，各有解說與小測|語言理解等|沿用K13～K18|

新增276道固定加練題，重用既有音檔，另保留既有基本小測、音韻題、筆順與手寫。每輪最多5或10題；只有3字的行別不補無關題來湊數。可選一行或全部46字混合。

聽辨干擾項排除同音選項，例如お與を不放在同一題當互斥答案。雙套字形配對可以比較視覺相近字；詞中補字接受指定假名，以字形正規化處理全半形，不能把另一套字形或羅馬字當同一答案。

## 4. 每日使用方式

|可用時間|建議循環|份量原則|
|---|---|---|
|5分鐘|先複習少量舊字→看一條訣竅→5題以内加練→手寫一字|新內容一次3字左右，視個人速度減少|
|15分鐘|到期弱項→新行3～5字→5～10題→遮字寫→記下最容易忘的一字|混合認字、聽辨與自己的輸入|
|30分鐘|兩個短循環，中間休息；第二輪換題型或平片方向|不以一次大量題數堆出熟練|

時間為建議，不是倒數通關。可離開或重新整理，已保存的題目、首答、提示與填空草稿保留。首頁與原五十音字表都能進入「記憶小訣竅＋三種加練」。

## 5. 錯題、提示與記憶證據

- 到期且最近錯答或用提示的字優先，再抽尚未練過的字；同組順序打亂。
- 每輪首次答案不可改寫。提示後答對仍標記用過提示，不算無提示成功。
- 答錯後展示參考答案、詞例與記憶訣竅；後方有至少兩題且有未曝光變式時安排一次訂正，避免立即照抄。
- 同日訂正不重寫首答，也不推進跨日複習。短輪間隔不足或沒有未曝光變式，明示留待後續／隔日；本批固定假名題不以立即重問原題冒充換題。
- 認字、聽辨、詞中運用分開記；手寫為作品與自評，不是假名自動辨識。
- 複習沿用既有1／3／7／14／30天起始安排，並依實際首答與提示更新。此排程不是所有人的最佳間隔保證。
- 不只看總答對率，也看隔天首次無提示回想、跨行辨認、從詞中辨字及作品。

## 6. 手機頁面與操作流程

字表或首頁→記憶加練→平／片假名→選一行→選題型→開始5／10題。已建立的未完成輪次另有接續入口，改選篩選不會抹除舊輪次。

記憶頁上方是小份量練習；下方為逐字提示與筆順。可一次隱藏字形、配對字、詞例與訣竅，只留聲音線索。由此進入默寫時，標題與畫板標籤也不顯示範字；寫完再點「對照示範」。

沿用今日／課程／練習／檢定／我的導航、大字設定、至少手機320／390px驗收，不引入另一套帳號或複雜選單。

## 7. 資料、離線與品質

進度仍存在IndexedDB，同一瀏覽器來源內延續V1～V3資料。題庫新增ID，能力事件保留原字卡ID；新kana練習來源納入schema3備份驗證。既有首答、作品、模擬與排程不重置。

文字、筆順與新頁納入離線shell；音檔使用既有假名包。需先連線完成下載，不能把文字可離線等同音檔已全部下載。個人備份與作品不提交GitHub。

驗收包括：92提示唯一且詞例對應、276題有唯一可接受答案、同音干擾排除、音檔存在、弱項可回到到期複習、提示／首答／訂正／草稿續作、備份匹配驗證、遮字不洩漏範字、320／390px版面、離線索引及公開部署。
