# N5～N2 檢定課程記憶與複習完整規劃與完成矩陣

v0.37.0，2026-10-23，Asia/Taipei。延續容易學、容易記，一次交付四級主課的完整記憶循環。[執行計畫](plans/2026-10-23-jlpt-memory-complete.md)、[測試與發布證據](jlpt-memory-validation.md)。

## 學習路線

1. **只決定今天一小步。** 選 N5／N4／N3／N2，優先接續原輪；今天完成一輪便可收尾。沒有待接續時依七日、隔天、弱點、新課安排，不自動開新輪。
2. **先想，再翻卡。** 看中文想日文、看用途想句型、看漢字想詞例，每組最多三張。讀音、例句、接續、差異與原音按需展開；不熟項目隔兩張後最多再來一次，間隔不夠留下一輪。
3. **留一句自己的提醒。** 每課160字個人線索，與原課作文稿分開。輸入自動保存，重開先收起；找有線索的課程時只看狀態，不預覽私人文字。
4. **收起參考，做少量原題。** 每課三題包含語彙、文法、聽解；也能只選五能力之一，每輪一至三題。卡片自評不當作答對，手寫與文字作品不當檢定成績。
5. **留時間確認記憶。** 隔天只挑較早日期做過且今天未答的原題；七日自最後實際練習與參考滿七個台北日期。每輪最多三題、每課一題，每級每日隔天／七日各一輪。
6. **看紀錄，再回到應用。** 記憶地圖分開顯示五能力每日首答、每課已練原題／弱點／日期與最近八輪。逐題回顧保留原首答與提示，可回原課寫自己的句子或另外練筆順。

## 記錄如何解讀

本輪對答不等於隔天記住。曝光依原題每日最早時間保存；新卡、個人線索與回顧先保存再展示。看過本課參考後相關原題保守列為提示，正常聽解題的刺激音不當答案提示。跨日可比較數排除提示、缺較早紀錄、中間先練與同時戳重疊。未來紀錄不影響目前報表或安排。

activeExam、新檢定待完成輪、目前 V2 主課待完成輪會先收起新參考，只提供原輪接續。不替換原 ID 或清除草稿。原 V3、V2 與單筆原題首答也接受曝光衝突驗證；同時戳不同個人線索拒絕合併。保存失敗保持待存資料，先匯出再處理。
