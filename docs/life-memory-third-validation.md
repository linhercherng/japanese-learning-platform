## 實際範圍

- life-week：依cutoff內實際同題作答與參考日期，距最後練習及參考至少7個台北日期才納入。最多三題、每課一題；錯答／提示、到期與較早時間優先。不用新題填滿。每台北日一輪，與其他生活來源共一pending。
- life-map每日收尾：pending先接續；今日已有完整生活小輪便顯示完成與預告，不再持續推薦弱點。所有答案、建立及完成時間都不能晚於cutoff。仍可明確自行加練，同日重做不算跨日記住。
- life-schedule：只顯示實際練過的場景，每課最早一題可隔天／七日檢查的日期；最多六個場景並說明其餘數量。參考會延後七日日期，預告無答案或音檔，不造成曝光；不是系統通知。
- 七日結果與原輪回顧：原首答不改；作答前七個日期及未完成輪內參考另列提示，缺少較早紀錄、中途另練、同時戳或提示皆不列可比較跨日證據。正常聽解刺激音不當額外提示。來源路徑、接續、草稿、JSON備份與原課保留。
