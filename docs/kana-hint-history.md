# 五十音提示與回饋歷史（v0.40.0）

2026-10-24，Asia/Taipei。目標是讓「先想，再看」可追溯，保留原答案，不用新增分數刺激重複刷題。[執行計畫](plans/2026-10-24-kana-hint-history.md)、[驗收](kana-hint-history-validation.md)。

## 學習流程

1. 先接續原輪，先自己想；卡住時主動按提示。
2. 原首答保存後，先保存回饋事件，再揭開解釋。失敗時顯示重試與備份入口；原答案保持。
3. 從每週回顧或五十音弱點進入「提示與回饋時間線」，查看事件種類、台北精確時間及來源。
4. 回原字記憶地圖或原練習，隔天／七日再想。查看報表本身不增加提示。

## 完成矩陣

| 類別 | 保存內容 | 分析用途 |
| --- | --- | --- |
| 答前提示 hint | 主動提示、圖像提示、默寫提示 | 同日／當輪，七日輪按七日窗，影響當次獨立回想 |
| 答後回饋 feedback | V1／V2／V3首答後的解釋與比較字 | 不改當次首答；影響後續回想間隔 |
| 查看參考 reference | 字表、詞例、記憶地圖、筆順、手寫描寫／對照、展開字表與原工具揭示 | 影響之後回想；必要題幹、選項與必要聽力音訊不自動當提示 |
| 原始首答 answer | 新答案原ID／字ID／時間檢查點 | 區分新版已記事件順序與舊歷史不足，不複製答案內容 |
| 舊提示 legacy | 舊kanaHints最後已知提示時間 | 不還原未知過去、不補造舊檢查點；不足時仍待確認 |

時間線每頁20筆，支援全部／原字定位、上一頁／下一頁、返回弱點與原地圖。只呈現metadata，不顯示原答案文字、正解或私人線索。事件數不是作答數或熟練度；手寫仍是自評。

## 資料與判定

沿schema3新增optional `v3.kanaHistory={version:1,events}`，原kanaHints三欄與attempts保持。事件只含item/time/kind/ref，同字×種類×來源×精確時間去重；不同實際顯示時間分開保存。舊最後提示在第一次真實寫入時懶建legacy，唯讀不建簿。匯入合併聯集，檢查種類／已知208字／時間／來源／重複與首答連結，原答案衝突拒絕。

跨日與七日依原題×能力、當日最早首答與可見提示間隔；未來事件排除，同時事件保守。較早答前參考不再被較晚回饋覆蓋。新檢查點的答後回饋不倒灌當次提示；舊答案無檢查點且較晚legacy仍待確認。備份合併若補入較早參考，分析可改為需複習，原hinted旗標與首答不改。記憶地圖先建索引再分析，避免每答重掃事件簿。

V1／V2／V3的回饋先保存再揭開；失敗可重試，離頁返回仍有重試。事件時間表示準備揭示時的保存時間；切頁後取消揭示可能保守留下事件。一般教材已呈現在頁面後才偵測實際文字；參考保存失敗會提示未保存並保留待存可匯出，不宣稱能回溯所有舊觀看。

每簿最多60,000事件；到上限拒絕新寫入並要求匯出，不裁切。備份仍有12MB匯入上限。舊schema1／2／3可由新版讀取；新版含事件簿的備份須用新版匯入，舊程式不支援此optional欄位。回退前保留完整備份，不用舊程式覆寫新版資料。無清DB、cache或SW，無新依賴／教材／音檔／帳號或後端。
