# 日語學習平台畫面與操作流程

手機優先的畫面提案。正式視覺樣稿待規格審閱後製作，本文件定義資訊順序、主要操作與例外狀態。

## 導覽

手機底部保留五個入口：「今日、課程、練習、檢定、我的」。桌機將相同入口放側欄，課程右側可顯示學習地圖。字典查詢、振假名與音檔操作放在內容附近。

```text
今日
  ├─ 繼續上次課程
  ├─ 到期複習
  └─ 今日學習任務
課程
  ├─ 五十音
  ├─ 生活主題
  └─ N5 / N4 / N3 主線
練習
  ├─ 聽辨與聽寫
  ├─ 手寫與文字表達
  ├─ 發音跟讀
  └─ 錯題與收藏
檢定
  ├─ 程度診斷
  ├─ 題型練習
  └─ 計時模擬與分析
我的
  ├─ 能力與進度
  ├─ 作品集
  └─ 設定、同步、匯出與刪除
```

## 今日首頁

第一屏呈現每日目標、上次進度與一個「開始今日學習」按鈕；下一區是到期複習數量與預估活動時間。已完成時提供「今天已完成」與自由加練入口。

初次使用者看見從零開始、程度診斷及直接選課。中斷後回來的人先看見接續入口與較小的恢復任務，不用先處理累積所有複習。

## 五十音地圖與字卡

可切換平假名、片假名、濁音與拗音。表格按行呈現；每格有字形與可讀文字狀態，長按不是唯一入口。可選「本行練習」或「混合複習」。

字卡順序為大字形、播放音檔、讀音提示、筆順入口、詞例、練習按鈕。相似字用並列字卡說明。羅馬字預設作為初期可收合提示，不長期占主要畫面。

## 書寫練習

上方是字形或題目與可收合提示；中央為大面積格線書寫板；下方為復原、清除、看示範、完成。只在書寫板內攔截繪圖手勢，頁面其他區域仍可捲動。

描寫與默寫使用明確標籤。完成後顯示自評檢核及示範比較，讓使用者選擇重寫或加入複習。字跡作品是否保存由設定控制。

## 發音練習

示範播放、自己的錄音、交替回放分成可辨認的按鈕。錄音前先顯示用途與存放位置；錄音中顯示狀態與停止操作。第一版以自評清單為主。

權限拒絕、沒有麥克風、噪音或錄音失敗時保留原課程位置，提供重試或不錄音繼續的選項。

## 生活主題與單課

主題入口按生活情境呈現，另有程度篩選及「我能做什麼」標籤。同一主題顯示入門、進階、中級任務與前置建議。

課程第一屏為能力目標與情境對話；對話可逐句播放。下方依次呈現單字、句型、聽讀、跟讀與書寫；一次只展開當前活動，另可查看全課大綱。

## 複習中心

預設進入到期項目，可篩選認字、聽辨、書寫與文法。顯示這次練習量與可暫停入口；結果說明首次表現與本次重練改善。

錯題卡包含題目、首次答案、正確答案或參考答案、解析、對應課程、教材版本與再練入口。已修正題目顯示修正註記。

## 文法與漢字詳情

文法頁包括意思、結構、適用場景、限制、例句與相似表達比較。漢字頁包括日文字形、筆順、常用詞與對應讀音；使用者可只複習正在學的讀音。

振假名與中文翻譯可分別切換，按下例句音檔不跳離目前畫面。查詢後可回到原本題目。

## 檢定專區

選 N5、N4、N3 後顯示課程覆蓋、分科練習與模擬入口。開始正式模擬前說明時限、分區交卷、音檔播放方式及中斷規則。

練習模式可重播與看提示；正式模擬依設定播放、分區倒數、到時自動提交。練過的試卷標明已曝光，避免錯把記住答案當作能力提升。

結果頁以題型與弱點為主，附建議課程及下一次複習；平台成績名稱不使用「官方合格」或「官方證書」。

## 我的與作品集

呈現六個生活能力維度與檢定分科進度。每個維度標示資料來源、樣本不足或自評狀態。作品集保留日期、任務、原稿、修改稿及回饋。

設定提供字體大小、振假名、羅馬字、每日時間、音檔速度、錄音保存、匯出與刪除。雲端版本加入帳號與同步狀態；本機版清楚說明瀏覽器資料清除的影響。

## 教材管理畫面

先以儲存庫教材檔與審校流程管理，後續才建立網頁管理台。管理台需要課程編輯、預覽、音檔與筆順資產、版本比較、審校狀態、發布及停用題目。

未發布課不得出現在一般學習者目錄；修改已發布內容須產生新版本。

## 所有主要畫面的例外狀態

| 狀態 | 畫面行為 |
| --- | --- |
| 新用戶尚無進度 | 提供可開始的第一課，不顯示空白統計 |
| 載入中 | 顯示可辨識載入狀態，避免重複送出答案 |
| 音檔失敗 | 可重試、查看文字；不算作聽解答錯 |
| 本機儲存容量不足 | 明確告知尚未保存，提供匯出與清理選项 |
| 斷網 | 顯示可用離線課及待同步數量，不假裝已上傳 |
| 同步衝突 | 顯示兩版本與合併選擇，不靜默丟棄作品 |
| 教材停用 | 保留已完成紀錄，提供替代課程或重新排程 |
| 模擬中斷 | 保存已提交答案並標記未完成，不當作完整試卷結果 |

## 第一批畫面樣稿

建議先審閱五個靜態畫面：今日首頁、五十音地圖、假名字卡與筆順、手寫練習、生活單課。樣稿標明示範資料與無正式保存行為；確認操作順序後再接入功能。
