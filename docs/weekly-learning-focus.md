## 學習循環

首頁今日路線 → 沿用原學習／複習輪 → 首答與答後回饋分開保存 → 每週回顧 → 下一週能力重點 → 今天到期的原題 → 回週報看更新。

每週回顧維持最近七個台北日期；下一週明示為明天起接下來七個日期，並非週一開始的曆週或已儲存的未來排程。最多三項能力，日份量5分鐘只推薦一項。每輪完成便可休息，不自動升級或改變原目標。

## 本週成果與記憶證據

- 完成學習原輪：五十音小組、生活記憶與檢定記憶；完成複習原輪：三區隔天、七日與弱點原輪。另列未完成與時間／歸屬待確認。
- 原輪每道答案必須唯一對應已保存的原首答、能力、時間、正誤與提示值；完成日期計輪數，原作答日期計本週答案。跨週不挪動日期；未來或衝突的完成不算成果。
- 舊資料不記錄連結來源，因此這些是每日路線使用的原工具，也包含手動進入，不推測「一定從首頁開始」。四步每日安排的完成步數與書寫自查另列。

## 如何選重點與練習

目前仍需複習優先，其次舊歷史待確認、等待跨日確認，最後間隔維持。同類再依本週可比較失敗、需提示／錯答及紀錄不足排序（失敗10、需幫忙3、未知1），保留原日期、目標與固定順序作穩定排序。近期失敗不抹除既有成功證據，也不把所有曾錯過的題永久列弱點。

首頁每日同類挑題共用這份近期摘要，保留原1／3／7日規則、每字／每課一題及最多三題，5分鐘一題。下一週重點只在今天到期時開隔天／七日原輪；尚未到期清楚給日期。首頁既有同日補強保持。

五十音詞音／拼寫能力沿用原手動工具：有自然詞例接原生活詞，18張無自然詞卡接原詞中補字工具，附字體、分類、行段選擇指引，不虛構新詞或自動跨日輪。

能力重點預覽只顯示課名等metadata與原因，不露題幹、答案、音訊或私人草稿。開始時在交易內重新核對到期、原輪與當天完成；既有未完成優先，儲存失敗保留備份及重試，切路由或跨日不另造作答。
