# 日和第三版學習與記憶規劃

日期：2026-10-13。狀態：V3.0已授權實作；V3.1／V3.2仍為後續規劃。使用者已選定「學習與記憶效果：每日路線、弱點複習、課程深化」為第三版優先方向。

第三版讓學習者打開網站就知道今天先做什麼，在少量新知後主動回想，隔天以不同題目確認記憶，再把詞句用到自己的生活。每天的推薦都要說明理由，學習者仍能自由選課。

## 現有基礎與第三版的改進

第二版 v0.2.0 已公開於 GitHub Pages，包含18個假名單元、12個生活起步、90個N5～N3主課、60個生活情境、6套模擬卷及本機備份／離線。程式已有能力別作答、提示紀錄、首次答案與1／3／7／14／30天排程。

目前首頁依上次課程及未完成課程選下一課；每日分鐘設定未組成完整的學習任務。到期複習主要回到既有題目，錯題還沒有跨題目整理為可解釋的概念弱點。第三版將這些紀錄接成每日任務、概念複習和跨情境應用。

## 每天的學習流程

首頁上方只有一個主要入口：「開始今天的15分鐘」。下方列出今天的四個小步驟、推薦原因、實際到期總數與可以稍後做的項目。每日時間可選5／15／30分鐘，時間是預估，活動可暫停，不要求倒數完成。

| 活動 | 15分鐘範例 | 完成後得到的證據 |
| --- | --- | --- |
| 想起昨天學過的 | 約4分鐘，4～6個優先複習項目 | 首次答案、提示使用、能力別表現 |
| 理解一個新重點 | 約5分鐘，3個新詞與1個句型，或一小組假名 | 接觸過哪些概念，與之前的知識如何連結 |
| 換個題目自己答 | 約4分鐘，辨認／聽辨／填空／換情境題 | 能否在新問法下使用同一概念 |
| 寫一句自己的日文 | 約2分鐘，依生活任務輸出一個訊息 | 作品與具體自評，不冒充教師批改 |

5分鐘版以複習與一個小輸出為主；30分鐘版增加閱讀或生活任務。複習積壓時優先減少新項目，顯示「今天先練這8項，另有32項可稍後複習」，不把已完成今日安排顯示為清空全部欠項。

推薦順序：可接續的今日活動 → 到期且近期不穩的能力 → 易混淆概念 → 本課前置知識 → 少量新項目 → 一個生活應用。首次使用先選目標與自覺程度，可直接略過。例：「昨天看字答對，但聽音還不穩，所以今天先練聽辨。」答題較慢只影響時間預估，不單獨判為不熟練。

同一日計畫保存所選題目及中斷點。重新整理、離線或隔天回來都能恢復；切換每日時間會明示調整剩餘活動，保留已完成紀錄。

## 核心功能

### 1 每日路線

提供五十音、生活基礎、N5、N4、N3目標。目標與當日活動可手動切換；使用者可忽略推薦，自由選課。每日5／15／30分鐘的新項目上限初值為1／3／5個概念，實際題數與時間由試學調整，並非研究證明的最佳值。

有較多未穩定到期項目時，推薦將新項目降為0；仍可明示選擇「今天也學一點新內容」。完成一課和記住某能力分開呈現。

### 2 弱點與易混淆練習

每個教學概念連結題目、例句、能力、生活任務和必要前置知識。先建立30個重點概念的高品質標記，既有未標記題仍可正常練習。

弱點顯示「助詞に／で」「シ／ツ」「長音」「動詞過去式」等可理解名稱。系統從題目與錯誤選項提供「可能混淆點」，可選擇自行標記；不斷言知道學習者的內在錯誤原因。

假名先做6組：シ／ツ、ソ／ン、ぬ／め、れ／ね、は／ほ、わ／れ。每組依看字比較、聽音選字、遮住提示、默寫對照進行。聲音類再以促音／長音等教材中的對照詞練習。圖形差異以既有SVG和原創註記呈現，保留來源與授權。

一個概念準備至少3種有實質差異的練習形式或語境，共90個新增／重編題目目標；只有重排選項不算新題。能設計唯一答案的題目才自動計對錯，開放表達保留自評。

### 3 記憶與複習排程

沿用可解釋的分日排程作起點，加入本輪重練與提示漸退。答錯先給精簡理由，在至少2個其他項目後安排一次變式重練；內容不足時提供明示的對照練習，不連續無限出同題。

同一天重練答對標為「本次訂正」，不重算首次答案，也不連續推進跨日熟練度。提示後答對仍是需要提示的成功。正式模擬卷保持獨立計分，不把其原題安排成新的診斷題。

每項可呈現「剛學過」「需要提示」「隔天想起來」「跨日較穩定」，旁邊列實際日期、能力及作答數。認字、聽辨與自評書寫維持分開；資料不足顯示待累積，不提供未經驗證的記憶機率。

### 4 課程深化

深入課程採六步：能完成的生活目標 → 一個重點及前置提示 → 正例與容易混淆的例子 → 聽讀理解 → 不同問法回想 → 自己表達與隔天回顧。

文法說明補「什麼時候用」「句型如何組成」「和相近句型差在哪」「哪些例句不能套用」。每個選擇題補主要干擾選項的理由；閱讀題說明依據，聽解先作答再顯示關鍵句與逐字稿。

詞卡由字形、讀音、繁中詞義，延伸到常用搭配、句中讀音、中文到日文回想與生活句填空。提供自選記憶提示；提示不能直接抄答案當作獨立成功。

首批12個深化單元：4個假名單元（K01／K07／K13／K18）、4個N5主課、4個N5生活情境（自介／點餐／購物／問路）。N5主課依前置知識與內容審查選定。既有其餘課程持續可用，介面明示哪些已有深入練習。

### 5 生活輸出與學習回顧

寫作從範例 → 補資訊 → 換情境 → 自己寫，逐步收起提示。保留原稿與修改稿；依任務檢核「資訊完整」「詞句是否對照」「語氣是否適合」。同一任務可有多種正確表達，不用範文逐字比對自由作文。

例：先聽懂店員問內用或外帶，再寫「コーヒーを一つください。持ち帰りでお願いします。」最後改成自己要的品項與數量。隔天只給新情境，不先給原句。跟讀仍可選擇錄音回放，音訊維持當次頁面內處理。

每週回顧呈現已練天數、隔天無提示回想的分子／分母、首次錯誤與本輪訂正、生活作品、下週3個重點。避免把重複刷題數當作學習成果。

## 工程與資料

維持GitHub Pages、原生ES modules與IndexedDB。新建純函式每日規劃器、概念索引、重練佇列及週報；UI沿用目前路由與元件。第三版學習功能離線可用，既有課程素材可重用。

規劃schema3新增目標設定、每日計畫、概念對應、重練佇列及作品修訂關係。舊作答事件與作品原樣保存，新增概念分析以對應表推導；沒有對應的舊題仍可查看與複習。題目語意變更用新版本／ID，舊紀錄保留來源，停用錯誤題可查紀錄但不再推薦。

遷移採同一交易，失敗保留原庫；支援V1／V2／V3備份匯入，去重首答並驗證新欄位。繼續使用QA隔離庫；不使用真實個人進度作測試，也不把作品／錄音／備份上傳GitHub。

## 成效與發布標準

功能門檻：新用戶能三次操作內進入活動；既有資料保留；同日首答／訂正／提示分開；隔天題目與推薦理由一致；可中斷續學；教材及離線索引完整；核心頁面320～1440px與大字模式沒有橫向溢出。

學習觀察：試學約2週，依同類概念看隔天及第7天首次無提示回想、不同語境的回答、生活作品和自行完成每日流程的情況。題數、樣本數與缺測明示；比較時保留題目難度與重複曝光紀錄，不把提升直接歸因於程式。初期數據保留本機，可由使用者主動匯出，不增加遠端追蹤。

真人審校核對自然日文、可接受答案、干擾選項和音檔。真實iOS／Android要完成聽音、觸控書寫、安裝與離線續作，桌機手機尺寸模擬分開記錄。平台完成標準不承諾固定日數記住全部日文或保證檢定合格。

## 設計依據

主動回想可作為學習活動，Karpicke與Blunt的研究在科學文本學習中觀察到回想練習的效益；日語平台採此方向作設計參考，仍須自身試學驗證。[原研究](https://learninglab.psych.purdue.edu/downloads/2011/2011_Karpicke_Blunt_Science.pdf)

間隔練習研究顯示保留目標與間隔時間有關，不支持把單一固定排程當成所有人的最佳方案。第三版先沿用可解釋的起點，再觀察調整。[Cepeda等人的研究](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.2008.02209.x/)

生活課程以「能完成什麼」設定目標，參照日本國際交流基金的Can-do教學方向；自編課程不複製《いろどり》題文、音訊，也不將JLPT級別等同CEFR等級。[《いろどり》官方介紹](https://www.irodori.jpf.go.jp/en/about.html)
