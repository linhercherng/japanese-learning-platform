# 五十音記憶教練第一批

使用者已授權實作記憶地圖、混淆字專練、隔天檢查，測試後發布GitHub Pages。基底為最新main d48eaf4，保留導航遮字與檢定計時器修正。

## 設計與資料

- 地圖覆蓋既有208張卡，可篩平片／分類／能力／需要複習，點字看各能力的紀錄、訣竅、筆順及手寫入口。
- 認字、聽辨從attempts計算；每個台北日期只取首次答案作跨日證據，最新錯答／提示仍提示需複習。兩個日期的獨立首答成功顯示「已有跨日回想」，不宣稱長期熟練。手寫維持作品與自評。
- 混淆依實際首答選項產生，可雙向比較與做最多6題（平片辨認、聽辨、詞中補字）。同音字不當互斥聽辨選項；空白歷史顯示教材相似字入口，明確區分個人紀錄。
- 在既有attempt加可選kanaConfusion={target,chosen}，不變更schema或清除資料；舊備份不需此欄。新事件保留於備份與合併，即使整理舊輪次也不會消失。可從保留的舊輪次答案重建可證明的歷史混淆，不能從correct=false猜字。
- 隔天檢查每個台北日期最多建立一輪、最多10個字×能力，從較早日期已練過且今天尚未作答的認字／聽辨中挑選，到期與不穩優先。沒有舊紀錄不建立假進度，先引導基本加練。
- 使用V3輪次保存題目快照、首答、提示、續作與結果。新增來源kana-check與kana-confusion；新題目可由穩定ID解析，備份驗證來源與題目一致。
- 入口在首頁、五十音及記憶加練；沿用主要選單。練習中導航不得顯示目標字形或字組；單字詳細頁可顯示資料。離線殼包含新模組，音檔重用既有假名包。

- [x] 記憶地圖與入口：208卡可篩選、文字狀態與圖例、逐字可返回，320px／390px不溢出。
