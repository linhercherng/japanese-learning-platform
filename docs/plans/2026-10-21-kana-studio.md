# 五十音記憶教練第二批

使用者已授權第二批開發、測試及公開發布。基底df35013；沿用第一批208卡、備份schema3與目前位置導航。

## 功能與證據

- 圖像提示：原創SVG輪廓聯想＋完整字形／訣竅 → 只有聯想輪廓 → 第一筆前段 → 只留聲音。後三階不在標題、導覽、文字或隱藏內容留下完整範字。涵蓋208卡，聯想不是字源。
- 提示階段以可選v3.kanaHints保存（stage、updatedAt、lastHintAt）。舊備份可無此欄，合併依時間保留，不能由看過提示判定熟練。
- 聽音默寫：每字獨立KS草稿，聲音與無範字畫板 → 鎖定原字跡 → 示範與疊圖對照 → 保存作品／手寫自評。鎖定前看提示會持久標記，鎖定後不能修改原跡；已保存不能覆寫首答。既有描寫草稿獨立保留。
- 生活詞：以既有詞庫與少量原創補充常用詞，挑每字最多3個不同詞形／讀音；平假名練詞的讀音、片假名練實際常用字形，少見字沒有自然詞例時明示，不用轉寫假充生活詞。詞中所有目標均遮住，音檔及答案於既有V3首答／提示流程運作。
- 新V3來源kana-words，穩定kw題目ID與題目／來源一致性檢查；新音訊沿用本機Haruka合成並明示未教師審音，詞音加入K離線包。
- 入口：記憶地圖詳細頁／既有五十音；新根入口可選字。默寫與練習導航採通用名稱，刷新續作與備份往返保留狀態。

- [ ] 核心：提示階段／舊備份／合併；默寫隔離草稿、鎖定、提示、保存冪等與失敗不重置，先紅後綠測試。
- [ ] 內容：原創聯想圖形、生活詞挑選與補充、詞音、題目唯一性、所有目標遮字與同音／轉寫邊界。
- [ ] 頁面：四階提示、聽寫畫板與鎖定後對照、生活詞學習／短練；首批入口及導航整合。
