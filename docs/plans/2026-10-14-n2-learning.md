# N2內容與網站豐富化實作計畫

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans / subagent-driven-development to implement this plan task-by-task.

**Goal:** 將公開試用教材路線延伸至N2，並交付網站改版的優先順序、畫面與驗收規劃。

**Architecture:** 保留ES modules教材結構與IndexedDB schema3。N2以新增穩定ID加入課程、情境、詞彙、漢字、每日安排、能力練習、檢定與離線包；舊級別及進度保持可還原。模擬引擎支援2或3考區，N2用105＋50分鐘。整站豐富化另外交付規劃，不將未驗收雲端／語音評分功能標成完成。

**Tech Stack:** Node22、原生ES modules、Windows Haruka日語合成音＋ffmpeg、KanjiVG固定版本素材、PWA、GitHub Pages。

## 已知範圍與取捨

- N2首批24主課，每課12詞、2文法、3漢字、6句對話、至少450日文字自編閱讀（主張、理由、限制、推論）、8活動題＋2閱讀題、200～350字寫作延伸與自查。
- 20類生活／職場情境：各至少8詞、6句對話、5題及文字任務；400條補充詞，合併後至少500個N2詞形／讀音組合。
- 2套独立自編模擬：各70題，語言知識・讀解50題／105分鐘，聽解20題／50分鐘；短練15＋5題，各區5分鐘。題數是平台安排，並非官方題數／尺度分數。
- N2每日安排加入8概念、24回想題，保持首答／提示／隔題訂正／弱項能力紀錄；舊N5～N3題及卷不修改。
- 語音沿用本機合成；需要生成所有新增教材音檔、離線雜湊與漢字筆順，不用靜默假音檔替代。
- 原創公開試用教材，獨立程式與內容一致性審查不等同教師審定；來源只引用規則，不複製官方／商業題文或聲音。

## T1 教材

Create `app/content/n2.mjs`, `n2-scenarios.mjs`, `n2-lexicon.mjs`, `n2-exams.mjs`; tests `tests/n2-content.test.mjs`、`tests/n2-curriculum.test.mjs`。

先以動態import與具體品質約束寫失敗測試：課數、內容、唯一題目／答案、文章长度、拼字空格、題型、獨立卷與兩考區。再撰寫教材並測試。主課可由一位獨立實作代理完成限定檔案；母代理負責其他資料及整合，避免檔案衝突。規格與內容審查先於最後程式審查。

## T2 系統整合

Modify `catalog.mjs`, `concepts.mjs`, `practice-v3.mjs`與分級介面；`core/exam.mjs`、`core/v3-state.mjs`、`core/offline.mjs`、offline index與常態checks。

先測N2目標／每日路線／備份還原、N2兩考區短練／時限交卷與既有三考區相容。補分級入口、搜尋、能力練習、目標、離線包。修正硬編碼考區數而不改舊卷語意。

## T3 素材

執行 `node scripts/v2-materials-prepare.mjs`；擴充音檔生成器保持已存在音檔索引，不重寫舊聲音，只產缺檔並定期checkpoint。下載新增漢字的固定commit SVG，驗原bytes並抽筆順。`npm test`→`npm run build`→`npm run check`→`npm audit`。

## T4 規劃與驗收發布

Create `docs/website-v4-plan.md`, `docs/n2-validation.md`；更新課綱、規格及README／協作文件的當前狀態，歷史驗收保留。

改版規劃須回答：新增哪些內容及功能、優先序與學習價值、手機頁面與導覽、資料／成本／授權依賴、每階段可驗收項目。區分已存在的每日路線／弱項複習／五十音加練與真正新增項目。

隔離QA驗收N2選課／實際作答／首答與草稿重整／詞彙搜尋／漢字書寫／模擬兩區／目標與離線下載，手機320／390px。進行規格＋程式審查，PR／CI／合併／部署，正式URL雜湊及代表音檔驗證，提供成果與後續建議。
