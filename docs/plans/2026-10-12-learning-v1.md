# 日和第一版實作計畫

> 執行技能：superpowers:executing-plans；使用者已確認畫面並授權直接開發，依序實作與報告驗證，不重複要求批准。

**Goal:** 將已確認的手機樣稿轉成可保存進度、練完整假名、完成六個生活任務並安排複習的本機第一版。

**Architecture:** 保留 `prototype/`，另於 `app/` 建立原生 ES modules 應用程式。課程與筆順為版本化資料，學習狀態保存於 IndexedDB；備份經嚴格驗證後合併。合成日語 MP3 在製作時產生，執行時由本機播放；錄音僅在裝置內處理。

**Tech Stack:** Node.js 22.17.0 以上、瀏覽器標準 HTML/CSS/JavaScript、IndexedDB、Canvas、Web Animations、MediaRecorder、Node test runner。選擇 JSDoc 與 ES modules，減少第一版建置依賴；與先前 TypeScript 候選不同，此決策不改變已批准功能。

## 指令與結構

`npm run dev` 啟動 `http://127.0.0.1:18089`；`npm test` 執行邏輯測試；`npm run check` 檢查模組語法與內容；`npm run build` 匯出可由靜態伺服器託管的檔案。應用位於 `app/`，純函式位於 `app/core/`，內容位於 `app/content/`，工具位於 `scripts/`，測試位於 `tests/`。

風格：純函式以明確命名的 export 撰寫，例如 `nextReview(previous, result, now)`；資料不與 DOM 混合。使用者文字只經 textContent 或 HTML 編碼輸出。

## 任務

1. **進度、複習與备份**：先寫能力分離、同日重練、提示答案、0 值、非法備份、作品合併的失敗測試，再實作。指令 `npm test`，確認紅燈後綠燈。
2. **完整假名與素材**：92 個基本字、濁音／半濁音與拗音、K01～K18 編排、全部基本字的 KanjiVG 筆順、詞例與合成音檔。內容檢查須驗證 ID、資產、前置關聯與所有 92 字覆盖。
3. **六個生活任務**：L01、L02、L04、L07、L08、L09，包含詞彙、對話、讀音、解析、換詞或自由寫作與小測。以自編內容交叉檢查；獨立教師審校狀態如實記錄。
4. **介面與保存**：已確認外觀、完整字卡與筆順、描寫／默寫、手寫與文字草稿、音檔、跟讀錄音、本機保存狀態、生活單課、首頁與復習。以實際瀏覽器驗證刷新、恢復与拒絕權限。
5. **個人資料與交付**：設定、能力統計、錯題、作品集、JSON 匯出與合併匯入、取消與拒絕非法檔案、版本說明。驗證新瀏覽器恢復及錯誤檔不改動原資料。

每階段完成有意義測試及提交，再接續下一階段。正式 N5～N3 題庫、雲端同步、自動發音／字形評分不屬此版。

## 第一版驗收

- 92 個基本假名都有讀音、詞例與可播放筆順；濁音、拗音等課組可學習與練習。
- 音檔是真正可播放的合成日語，播放失敗有明確狀態；不是動畫冒充音訊。
- 兩種能力的作答、提示與首次正誤分開記錄；同日重複答同項目不冒稱長期熟練。
- 手寫與文字作品、自評與課程完成刷新可恢復；儲存交易失敗不得顯示成功。
- 至少六個生活任務有輸入、練習、文字輸出、解析及保存。
- 有效備份能在新瀏覽器恢復，非法／過大／未知版本檔案拒絕；合併不重複計數。
- 320～1440px 排版、核心學習流程、瀏覽器錯誤及個資隔離檢查通過。
