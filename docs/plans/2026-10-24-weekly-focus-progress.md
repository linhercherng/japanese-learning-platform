# 七天重點完成與改善追蹤 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 保存一組可回溯的七天能力重點，區分完成練習與可靠改善，讓週報與首頁用同一份原題證據接下一步。

**Architecture:** schema3新增可選的weeklyFocusPlans（舊資料不補空欄位），按使用者按下「追蹤這組重點」時保存日期、原題×能力與baselineAt，不保存答案副本或可修改總分。期間以原始答案及提示歷史唯讀重算；每日推薦只增加目前待鞏固的已追蹤原題優先，不改到期規則與原輪。

**Tech Stack:** Node22原生ES modules、IndexedDB、既有HTML/CSS與Pages；無依賴、日文教材或新音訊。

## 已決定的設計

- 延用上版動態下一週建議；另有一鍵保存的「七天重點追蹤」，從按下當天台北日期至第七天，明示日期。看週報／首頁不建立紀錄。未追蹤的歷史不假裝曾被推薦或完成。
- 同時僅一組有效期間；同日重按或七天內重按不替換。過期可開始下一組，舊組保留。最多260組，容量滿先提示備份，不自動刪除。5分鐘最多一個能力與一題，其餘最多三能力、每能力最多三原題。
- 每個目標只保存goal、ability、item、dimension及當時lastAt；metadata從原內容解析，baseline必須連到已保存原題，不信任匯入的宣稱。期間每題原首答完成與記憶改善分開。
- 追蹤後有新的、時間唯一的原首答才算「已練原題」。同日訂正或提示後答對可練但不算改善；有追蹤後的可比較跨日成功且目前期間末狀態仍可信，才列「弱點已改善」。已穩定題另列「維持想起」。仍需複習、等待跨日、舊歷史或碰撞待確認、尚未練分開。
- 過期組結果固定截至第七天，不用之後的作答冒充期間完成；較晚匯入更早提示可以更正證據。首頁以最新組原目標的「現在」狀態選待鞏固題，已改善不因舊錯答永遠優先。新組取代舊組的優先，不刪舊記錄。
- 待鞏固題只在同mode／目前狀態順位內優先；七日／隔天／同日補強原規則、每課一題、最多三題、5分鐘一題保持。全域未完成先接續、當日完成便休息、未到期不提前。五十音詞音手動入口保持可用原工具。
- 開始追蹤在交易內重算日期、候選與既有追蹤；候選或午夜改變則回畫面確認，不保存與預覽不同的一組。保存失敗原資料保留，可重試／匯出待存備份；離開頁面不搶路由。
- 備份驗證嚴格、合併追加；同id不同內容或期間重疊拒絕並保留原備份，不能覆寫首答、草稿與作品。無新個人資料上傳。
