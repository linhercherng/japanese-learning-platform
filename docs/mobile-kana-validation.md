## 實際瀏覽器流程

- 選ぬ → 圖像 → 輪廓 → 起筆前段 → 只聽聲音 → 重新整理：階段保留，後三階無完整範字；導航不露答案。
- 從提示頁進默寫：保留同日使用提示標記。畫板拖曳後重新整理，字跡保留；退一筆後空白不可鎖定。
- 再寫 → 鎖定 → 疊圖 → 重新整理：原稿保留且無可編輯畫板；沒有確認自查時不能保存。勾確認後保存，作品與手寫首答各新增1件，結果仍為自評。

## 問題與修正

1. 生活詞練習的breadcrumb原本回選字根頁。改為保留原字卡reference，文案仍為通用名稱、不露題目答案。瀏覽器與回歸測試通過。
2. 活動pointer尚未結束時undo／clear移除stroke，後續move可能讀取不存在的stroke。先清pointer ownership並釋放capture；dispose冪等，避免lostpointercapture重複保存。觸控事件測試先紅後綠。
3. 五十音平／片切換按鈕原高42px，調至44px；320／390px實測44px。原表單字級已16px，沒有為縮放而禁用瀏覽器放大。
