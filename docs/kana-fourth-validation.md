# 五十音記憶第四批驗收（v0.8.0）

2026-10-21；使用者授權規劃、實作、測試及GitHub／Pages發布。基底634eee5；[實作規劃](plans/2026-10-21-kana-fourth.md)。

## 交付

- 聽音打字回想（#kana-type）：190卡、509題，沿用既有自然詞／假名讀音與K包音檔，每卡最多3詞。要求題目指定平／片假名，NFKC接受半形片假名，漢字／羅馬字／另一套字形不列正確。提示後才顯示答案或個人線索；草稿、首答、固定題目與備份保留。18卡沒有自然片假名詞，明示並提供平假名入口。打字記為詞語運用，不代替聽辨或手寫。
- 七日回想（#kana-week）：字卡×認字／聽辨分開，最近同能力作答至少隔7個台北日曆日，近期已紀錄圖像／線索提示也會延後。最多10題、弱項優先，沒有符合資料不硬補新字，可查看最早日期。未完成先續原輪、每天一輪，返回來源不顯示答案。結果排除中途先練過與不能比較的紀錄。
- 回想小結（#kana-recall）：最近7個台北日期，以同字×能力每日第一筆為單位，分認字／聽辨／詞語運用顯示數量；同日多次詞練習不增加成功數。手寫只列自評，最多3個實際需複習字提供記憶地圖入口，另列七日檢查數。

## 資料與審查修正

schema3增加kana-type／kana-week來源，沒有新資料庫或個資上傳。kt題目依完整穩定詞庫解析，來源、reference、queue與同日唯一輪次皆驗證。V1／V2／V3原資料、原始首答、個人線索及清除tombstone保留。

審查找到並修正三項提示邊界：V3看提示須更新假名字卡曝光，同字未答七日題及配對字形也保留；兩備份分支的曝光／無提示首答矛盾拒絕合併，不改寫原首答；合併進來的開輪前近七日曝光也不能支撐七日無提示證據。新回歸均先失敗再修正通過，核心及UI／內容獨立複核無新增重要問題。

輸入法composition中與空白答案不記錯，pointerdown保存按下時的composition狀態，涵蓋compositionend先於click的順序；完整文字仍能從交易失敗的待存備份匯出。

## 邊界與回退

IME事件防護由控制器事件測試確認；瀏覽器以填入假名／半形文字驗收，沒有操作真正的系統日文IME。iPhone／Android實機鍵盤與觸控仍依使用者先前決定略過。沒有長期記憶效果實證、自動手寫／發音評分或雲端同步；公開試用教材與合成音仍待獨立教師審校。

七日資料依已有紀錄判斷，未記錄的紙本練習／站外提示無法偵測，不等同受控實驗或正式檢定。

回退前先匯出完整JSON；新來源的備份不保證舊程式能解析，保留原檔待新版恢復。部署可回退，無破壞性schema遷移，不清除IndexedDB。
