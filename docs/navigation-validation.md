# 目前位置導覽驗收

2026-10-16，v0.4.2。使用者回報點入連結後容易失去所在路徑。

## 變更

- 共用「目前位置」路徑固定於頁頂，父層可點回，所在頁使用 `aria-current="page"`；標題完整換行。
- 課程、生活分類、學習補給、資料庫、五十音、書寫、每日安排、深化課程、檢定與作品修訂均有路徑。
- 課內回想從保存的來源課程重建路徑；一般能力、詞卡與到期複習各自回到有效目錄。
- 學習補給會點亮底部「課程」與桌面「全部課程」，練習時點亮「練習」。瀏覽器標題隨目前頁面更新。
- 生活分類同步 `#topics/<分類>`，返回與重新整理保留分類。
- 遮字、默寫與回想使用通用活動名稱，導覽不額外顯示答案、目標字形或使用者作品。
- 沿用既有本機進度與備份格式；無資料庫升級或清除操作。
