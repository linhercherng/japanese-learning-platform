## 教材與素材

`scripts/v2-check.mjs` 驗證90主課、60場景、12生活起步、6卷、1,656唯一固定題ID、答案／選項／填空／詞塊、分級讀解長度、教材必填欄位與完整離線清單。主課各有8綜合題＋2讀解題；不與模擬卷共用ID。跨級去重3,205詞，各級標籤1267／1502／1735；漢字312、主課文法180。

`scripts/materials-check.mjs` 驗證208假名與312漢字的筆順、460原始SVG的來源與SHA-256，以及詞中讀音、例句、短文、場景與模擬聽解音訊實檔。`scripts/materials-decode.ps1` 使用ffmpeg實際解碼全部9,540唯一MP3成功；不等於教師審音。

## 邏輯與獨立複查

`npm test` 50／50、`npm run build`與`npm run check` exit0。測試涵蓋跨日間隔、提示、不重複事件、遷移與備份合併、練習續作、明示填空變體、詞塊、模擬絕對期限／逾時／續考、交易內最新答案、同場與跨考區備份衝突、離線取消／缺檔／HTML偽音訊、版本快取與Range206／416。

不同模型唯讀複查發現並修正：逾時交區延長時間、舊快照覆蓋首答、刷新重設提示、分級與詞卡到期題無法練、備份續作被丟棄、HTML被誤當音訊、回想上限無整理入口、同場試卷分歧、下載未確認就整理、過期shell雜湊。最終複查未見確證阻擋交付項目。

內容抽樣修正N5田中聽解未明示行為、N4「使用／利用」兩個同義正解。N3卷拆分本文與題目，避免整篇作題目標題；並補每課情境詞與相關漢字，實際去重數如實報告。

## 未驗收邊界

真實iOS／Android觸控筆、手指、安裝、背景回收與麥克風尚未以實機驗收。沒有雲端帳號同步、公開端點或真人語音；私人GitHub推送不是公開上線，單瀏覽器的備份匯入不是兩台裝置同步。
