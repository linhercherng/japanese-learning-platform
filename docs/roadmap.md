# 日語學習平台版本與交付路線

此路線為完整範圍的分期提案。產品規格待審閱，技術實作任務與套件選型須在規格確認後定稿。每次交付都包含程式、已審校內容及對應驗收。

## 交付階段

| 階段 | 產品與內容 | 出口條件 |
| --- | --- | --- |
| P0 規劃與樣稿 | 規格、課綱、流程；規格確認後製作五個畫面樣稿 | 使用者確認第一版範圍與畫面 |
| P1 五十音可用版 | K01～K18、基本音檔、筆順、手寫、自評、複習、本機進度 | 完整基本假名可學可練；核心循環與備份通過驗收 |
| P1 生活試學 | L01、L02、L04、L07、L08、L09，共 6 個主題 | 每主題有聽讀與文字輸出；內容審校通過 |
| P2 生活與 N5 | 補齊 L01～L12、N5 24 課、20 類主題的入門任務、N5 題型 | 完整 N5 路徑與生活任務可用，至少兩套獨立模擬卷 |
| P2 跨裝置 | 登入、同步、指定離線課、本機到帳號資料搬移 | 兩裝置新增／更新／恢復、衝突與隔離驗收 |
| P3 N4 | N4 30 課、生活進階任務、漢字與詞彙擴充、N4 模擬 | 至少兩套獨立模擬卷與生活文字任務審校完成 |
| P4 N3 | N3 36 課、生活中級任務、篇章閱讀、自然語速聽解 | 至少兩套獨立模擬卷與短文任務審校完成 |
| P5 輔助評量 | 字形輔助、發音分析、作文輔助、管理台 | 各功能完成可信度測試、成本與資料處理確認後獨立發布 |

六套模擬卷為正式檢定版本的初始交付目標，不代表題庫已存在。每套的題數與題型分配在題庫設計時定稿；題目、選項、音檔及解析須成套審校。P5 功能不應拖延前面的可用版本。

## 第一個端到端試作

完整五十音上線前，先用あいうえお建立最小可用循環，確認音檔、書寫、作答與保存能共同運作。下表為規格確認後的候選任務；檔案數與正式指令於技術方案定稿後補齊。

| 任務 | 依賴 | 驗收 | 驗證方式 |
| --- | --- | --- | --- |
| T01 建立 K01 審校教材包 | 規格與資產策略 | 五個字有字形、音檔、筆順、詞例與來源 | 逐字內容與授權檢查 |
| T02 字卡與聽辨循環 | T01、畫面確認 | 可看、可聽、回答新題、看解析 | 真實瀏覽器逐步完成 |
| T03 手寫與自評 | T02 | 描寫、默寫、復原、比較與自評可用 | 手指、滑鼠、觸控筆操作 |
| T04 保存與隔日複習 | T02、資料規格 | 刷新恢復進度，認字與聽辨分開排程 | 跨日時間情境與刷新測試 |
| T05 備份與恢復 | T04 | 可匯出並在新環境重建；非法檔不破壞原資料 | 有效備份、錯誤檔及版本差異測試 |

檢查點一：T02 後審閱字卡與題目體驗。檢查點二：T04 後審閱完整循環與能力紀錄。T05 後再擴充其他假名，避免大量教材依賴未驗證的互動。

## 技術方向提案

| 區塊 | 建議方向 | 選擇理由與待確認事項 |
| --- | --- | --- |
| 介面 | 網頁、TypeScript、適合互動學習的元件架構 | 共享手機與桌機介面；框架與版本待技術規格確認 |
| 手寫 | SVG 筆順資產與可記錄筆劃的繪圖區 | 動畫與實際筆劃可分開處理；先驗證觸控行為 |
| 教材 | 版本化結構資料、資產索引、審校狀態 | UI 與課程內容分開，新增課程不需改頁面邏輯 |
| 第一版本機資料 | 支援結構資料及作品的瀏覽器儲存 | 需提供備份、容量處理、遷移規則；儲存實作待選型 |
| 雲端版 | 使用者認證、資料庫、私有檔案儲存 | 使用者隔離、備份與裝置同步；供應商與費用待確認 |
| 離線 | 可選課程包、版本化快取與同步佇列 | 課程與媒體各自管理，不預設下載全部音檔 |
| 語音 | 已審校錄音，後續可選分析服務 | 先確保可用音檔與回放，再驗證評量品質 |
| 部署 | 正式 HTTPS 與可回滾版本 | 錄音授權、服務狀態、真實裝置與登入需線上驗收 |

暫不選定後端與部署供應商，因此不預設現有帳號、金鑰或配額。技術方案定稿須比對當時官方文件，確立安裝、開發、建置與測試指令；目前沒有可執行的應用程式指令。

## 測試與發布標準

- 邏輯測試覆蓋排程、跨日、提示後作答、試卷分區倒數、備份驗證與匯入去重等會造成錯誤紀錄的行為。
- 整合測試驗證教材版本、資料隔離、保存與同步；不能只測畫面能否開啟。
- 實際瀏覽器驗收字形、振假名、音檔、手寫區與中文介面，檢查控制台與網路錯誤。
- 行動驗收在真實 iOS Safari 及 Android Chrome 執行；桌機驗收不能取代這兩項。
- 雲端驗收區分兩裝置基本同步、離線回復、作品衝突與帳號隔離，不以單一成功案例代表全部完成。
- 每次發布做教材審校抽查、可回滾檢查與資料恢復演練；驗收證據與已知限制存入文件。

## 教材產能與資源

程式與教材是兩條相互依賴的工作線。內容需要課綱編輯、日語教學審校、錄音與音檔核對、題目及答案驗證；一個人可兼任，但正式教材要有第二次獨立審校。

先以 K01 與一課生活教材記錄實際製作、錄音與修訂工時，再估算全部課程。未完成此試作前不給固定完工日期。每階段先做小量試學，再擴充剩餘課數。

第一版費用類別以網頁託管、教材錄音、筆順與插圖授權為主；雲端版另有資料庫、檔案儲存、流量及可選 AI 服務。導入付費服務前列出供應商、方案、月上限與達上限行為；不先承諾免費。

## 風險與處理

| 風險 | 對策與發布門檻 |
| --- | --- |
| 課程與音檔產能不足 | 先完成小課試作，再按驗收分期發布 |
| 日文錯誤或不自然 | 每課審校、來源紀錄、學習者回報及可回滾版本 |
| 手寫誤判 | 第一版自評，後續用多樣樣本與可修正回饋驗證 |
| 發音評分不可信 | 自評與客觀資料分開；低信心不給確定分數 |
| 考試規則改變 | 規則版本化，發布前重新查核官方來源 |
| 個人資料遺失 | 本機備份、保存狀態、雲端恢復演練 |
| 離線同步衝突 | 事件去重、作品雙版本與衝突處理驗收 |
| 語音或 AI 費用增加 | 用量上限、重試限制、降級回基本練習 |
