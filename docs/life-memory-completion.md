# 生活日語記憶與複習完整盤點與收尾

日期：2026-10-23。版本v0.36.0。使用者要求不再分批，一次完成剩餘部分。本次以生活記憶與複習的完整程式循環為範圍，將前十四批與最後入口整合一併交付。

## 一條完整學習路線

從[今天怎麼練](https://linhercherng.github.io/japanese-learning-platform/#life-path)開始，先接續未完成原輪。今天已完成一輪可收尾；沒有已完成輪次時按原規則建議七日、隔天、弱點或新場景。推薦不自動開始，也不改作答或學習進度。

新學從92個場景選一課，只挑一句。三句參考與逐句雙向卡連起意思與聲音；中文回想、聽寫各有自己的原稿。卡住可以逐步借開頭，寫後對照，先看一處差異再遮住補回，最後接整句空白再想。片段只暫存，整句再想稿另存，原稿保留。

[我的生活練習簿](https://linhercherng.github.io/japanese-learning-platform/#life-workspace)統一找到中文回想、聽寫、兩種再想稿與生活線索。按課名、場景或自己的文字明示搜尋，搭配程度、種類及狀態；每頁最多10筆，空白草稿仍可找到。索引不預覽日文或個人文字，不記參考曝光，不新增作答；點進去仍先收起內容，再主動展開。線索待保存稿與已保存值分開保留。

原題能力專練、同主題換已學場景與原課文字作品提供輸出；隔天與七日只取實際練過且符合日期的原題。小結／地圖保留每日首答、提示與可比較跨日證據，不以同日重做宣稱記熟。[完整六段指南](https://linhercherng.github.io/japanese-learning-platform/#life-guide)解釋每一步何時用、如何接下一步，不必全部工具都做。
