# 日語學習與練習設計

以「能獨立辨認、理解與表達」作為學習成果。每堂課都有輸入、練習、輸出與間隔複習，練習模式與考試模式採不同提示規則。

## 每日學習循環

首頁先列到期複習，再提供一個新知識活動與一個短輸出。預設 15 分鐘可分成複習 4 分鐘、新知識 5 分鐘、練習 4 分鐘、整理 2 分鐘；時間為設計目標，不強制倒數。

1. 看本課能力目標，例如「能聽懂並寫下五個母音」。
2. 聽完整示範，再看字形、詞義、句型或情境。
3. 小組練習，每次處理少量新項目；出錯可看提示。
4. 進行無提示辨認、聽辨、默寫或短句輸出。
5. 以新題檢查，說明錯在哪裡與下一步。
6. 更新能力別紀錄，安排下一次複習。

複習累積太多時，首頁推薦「今天先複習」並降低新項目數量。一天沒學不清空進度；連續學習天數只是附加資訊。

## 五十音練習的六個層次

| 層次 | 題目形式 | 能力證據 |
| --- | --- | --- |
| 看字認音 | 顯示あ，選音或讀音 | 字形與讀音連結 |
| 聽音認字 | 播放音檔，選假名 | 聽辨能力 |
| 描寫 | 看筆順，在格線上描寫 | 學習過書寫動作 |
| 提示逐步減少 | 只留起筆點或淡化字形 | 對字形與筆順的記憶 |
| 默寫 | 給讀音或音檔，無字形提示 | 獨立寫出字形 |
| 放入單字 | 聽寫或閱讀生活單字 | 能在語境中使用 |

描寫成功不等同默寫熟練。每個字的認字、聽辨、書寫各自有最近表現與待複習狀態。

## 手寫回饋

第一版提供筆順動畫、格線、淡字描寫、清除、單筆復原、示範疊圖與自評。自評項目為筆畫是否齊全、順序是否符合示範、相對位置是否合理、是否容易與其他字混淆。

手指寫字與觸控筆精度不同，第一版不因字跡不美直接判錯。無觸控裝置可使用滑鼠，或選紙筆練習並自評；紙筆自評不宣稱平台已辨識字形。

後續輔助評量需要保存筆劃軌跡，分別檢查筆畫數、順序、方向與相對位置。只比較最後的圖像不能推斷筆順。評量必須以多種可讀手寫樣本驗證，包括正確變體與常見誤寫，才決定是否能顯示自動回饋。

默寫評量若採自評，標為自評證據；若採自動辨識，附信心與可修正入口。不能把兩種資料混成精確的書寫能力分數。

## 發音與聽力

基礎課提供正常速度示範與保留音高的慢速播放；單字及句子標記適合程度的音拍、重音與語調。真人日語錄音為目標，尚未審校的合成語音只用於原型並清楚標示。

練習順序為聽一遍 → 看解說 → 跟讀 → 錄音 → 與示範交替回放 → 自評長短音、促音及節奏。錄音選用，不以麥克風授權作為完成課程的先決條件。

正式聽解練習先不顯示逐字稿；完成後才提供逐句音檔、逐字稿、振假名與繁體中文解說。可依能力開啟逐字稿的輔助練習模式，但成績與無提示聽解分開。

後續自動分析拆成「辨識出的文字、可理解度提示、節奏與音長」，再評估重音。語音辨識文字正確不等於發音正確；低信心或噪音時顯示重錄提示，不強制給分。

## 生活課程範本

每課結構固定：能力目標 → 情境對話 → 關鍵詞 → 句型與禮貌 → 聽讀練習 → 跟讀 → 書寫 → 任務小測 → 複習。

以餐廳課為例，N5 任務是「能點一份餐點並寫下品項」：

- 情境：店員問「ご注文は？」；學習者說「カレーを一つお願いします。」
- 單字：カレー、水、メニュー；數量表達單獨解說。
- 練習：聽出品項與份數，選擇符合需求的句子。
- 書寫：默寫片假名品項，再依模板輸入點餐句。
- 小測：換成不同品項、不同份數，避免只記住示例。

N4 同主題加入飲食限制與理由；N3 加入訂位、更改與問題反映。真實情境可接受多種恰當表達，解析說明各答案的語境。

## 書寫與文字表達

手寫練習重點是字形與動作；鍵盤輸入練習重點是文字選擇與句子表達，平台分別紀錄。

| 程度 | 練習 | 回饋重點 |
| --- | --- | --- |
| 假名 | 描寫、默寫、短詞聽寫 | 字形、筆順、相似字、音與字 |
| N5 | 助詞填空、排序、仿寫、簡短日記 | 句型與基本語意、肯否、時態 |
| N4 | 訊息、日記、邀約、經驗描述 | 活用、句子連接、需求與禮貌 |
| N3 | 理由、意見、摘要、實用短文 | 段落邏輯、語境、表達清楚與語氣 |

封閉題由已審校答案判分；自由回答先採參考答案與自評檢核。後續加入教師或 AI 回饋時，提供原句、問題位置、原因、修改建議與另一種自然說法；保留原稿及修訂稿。

AI 的語言建議須標示為輔助回饋，可回報或忽略。無法確定的句子不假裝唯一正解，也不因未使用某個參考詞而直接判錯。

## 複習排程提案

按項目與能力維度分別排程；同一個字可能認字已熟、聽辨待練。首次學習結束後，初始間隔可使用 1、3、7、14、30 天作為簡單規則，試用後再調整；此規則不宣稱已驗證最適。

學習者可選「忘了、需提示、想一下才會、熟悉」。客觀題優先使用首次正誤與提示紀錄；手寫、跟讀則保留自評來源。

忘記的項目縮短下次間隔，當次可重練，但重複同題答對不能取代隔日回想證據。超量時依到期、最近錯誤、前置能力排序；一天的複習量可調整並顯示剩餘項目。

每次作答保存項目、教材版本、能力、時間、首次答案、提示次數與結果。答案覆核或教材修正以新事件補充，避免直接抹去歷史。

## 熟練與推薦門檻提案

- 認字與聽辨：最近至少 10 個有效獨立作答，跨至少 2 個學習日，無提示首次答對率達 85%，才標為暫時熟練。
- 未足樣本時顯示「證據不足」，而非把一次答對當作 100% 熟練。
- 自評書寫：跨至少 2 日完成無字形提示練習並達檢核，標為「自評熟練」；自動評量的門檻待驗證。
- 階段推薦：新題綜合小測達 80%且沒有主要前置缺漏，可推薦進下一階；使用者可手動繼續。
- 這些是平台提案門檻，與 JLPT 官方及格分數不同；正式值由試用結果與審校決定。

## 檢定準備循環

程度選擇 → 分科診斷 → 課程補強 → 題型練習 → 未見題小測 → 分區計時模擬 → 弱點複習。

模擬報告呈現首次答對率、各題型錯誤、閱讀用時、聽力弱點與建議課程，不以答對率線性換算官方 180 分。JLPT 採尺度分數，平台尚無等化資料時不顯示官方分數預測。[JLPT 官方 FAQ](https://www.jlpt.jp/sp/e/faq/)

## 成效觀察

試用以隔日與一週後新題保留率、生活任務完成程度、實際可讀的書寫作品、可理解的錄音，以及使用者能否持續完成每日循環作為指標。先收集基線，再設定改進目標；不預先宣稱課程已證明有效。
