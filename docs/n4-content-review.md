# N4 教材交付與審校狀態

日期：2026-10-13。這批為平台原創試用教材，級別按課綱編排，尚未經獨立日語教師審校。

## 已交付

- `app/content/n4.mjs`：30 個單元，六課組各五課。每課 12 個附例句詞條、兩個文法說明、六個漢字項、至少六句對話、201～252 日文字符讀解、八題主練習、兩題獨立讀解、書寫範例與三點自評。360 個主課詞條按字形與讀音去重後仍是 360 個；漢字去重後 151 字。
- `app/content/n4-scenarios.mjs`：20 種生活分類各一個 N4 任務，每場景六個相關詞、至少六句對話、四題及書寫任務，共 80 題。場景依序包含學習動機、澆花請託、改約、飲食限制、換貨、誤點轉乘、寄放行李、雨天變更、症狀經過、失物描述、作息變化、補交作業、工作交接、陶藝、跑步活動、报修、寄件、窗口填表、資料保存及送禮習慣。
- `app/content/n4-lexicon.mjs`：按學校、工作、家庭、日程、飲食、購物、衣著、交通、旅行、自然、身體、居家、公共、通訊、文化、動詞、感受及連接表達等語義群整理，1149 個詞庫項。與主課合併後 1499 個去重詞項，含必要基礎複習，不能把全部稱為新增 N4 官方詞彙。
- `app/content/n4-exams.mjs`：A、B 兩卷各 70 題，20 文字語彙、30 文法讀解、20 聽解。涵蓋漢字讀音／表記、語境、近義與用法、文法選擇、句子排序、文章文法、通知／訊息／經驗／資訊檢索、課題與要點聽解、即時回應。兩卷與課內練習分離，沒有複製官方題目、文章或聲音。

N4 分科時間採 25／55／35 分鐘，已於 2026-10-13 核對 [JLPT 官方科目與時間](https://www.jlpt.jp/e/guideline/testsections.html)。題數是本平台練習設計，不宣稱與每次正式試卷相同；原始答對率不得換算成官方尺度分數。新版沒有公開完整官方詞彙／漢字／文法清單，詞量是內部教材容量，參見 [JLPT 官方 FAQ](https://www.jlpt.jp/e/faq/)。

## 已做資料檢查

專屬 Node 檢查確認 30 課與 20 場景、每課欄位與最小數量、讀解長度、520 個題目 ID 全部唯一、答案索引在有效範圍、填空接受值非空、排序索引完整不重複、聽解逐字稿非空、兩卷分科題數與時間、詞庫去重及實際字數。閱讀題沒有重複放進主練習。排序詞塊逐句編排，未採字元平均切割。

教師審校仍需確認：句型活用與語境限制、所有讀音與詞義、每個干擾選項是否只有一個最佳答案、文章難度與原創性、中文解說、錄音朗讀及考卷難度。程式檢查不能證明教學或日語母語品質；本交付也未替本版完成手機或離線功能驗收。
