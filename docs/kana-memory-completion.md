# 五十音記憶功能完整盤點與剩餘整合

日期：2026-10-23。整合版本v0.21.0。使用者要求規劃並實作剩下功能，本次以原記憶規劃A～C為範圍，不把D所需真人／實機證據假裝完成。

## 容易學、容易記的完整循環

1. 開[今天怎麼練](https://linhercherng.github.io/japanese-learning-platform/#kana-path)：先接續未完成練習或默寫原稿；沒有pending時，依日期看七日、隔天、已知弱點及口袋需要。當日同類已完成就不重複推薦，今天已有回想且沒有待做項目時可以收尾。
2. 初學先一行或三字，選一處字形線索；收起圖像與選項，再自己想。平片、標記家族與相似字按自己的需要選，不必所有入口都做。
3. 放回不同生活詞，再試拼詞、打字或默寫。音檔完整播放，拍格與拼字塊分開；寫完鎖定原稿才自查。
4. 用[我的線索簿](https://linhercherng.github.io/japanese-learning-platform/#kana-notes)回找自己的聯想與草稿。搜尋文字／假名／輔助讀音，篩平片、分類、口袋或未保存草稿；每頁最多10字，未顯示頁不預記曝光。
5. 隔天／七日符合日期與提示條件才檢查；看記憶地圖、小結與原首答，不用當天反覆刷題證明熟練。完整[六段指南](https://linhercherng.github.io/japanese-learning-platform/#kana-guide)解釋各工具何時使用。

## 本批設計與資料

今日推薦只讀保存紀錄，不自動開題、清空或移出口袋。時間快照先過濾attempts再重建reviews；未來session／hint／口袋不影響當下建議，題目與字形不出現在推薦卡。全日已完成同來源不再推薦，但可以自由另外練。認字／聽辨／詞語回想的今日字數去重；手寫自評不混入，沒有熟練總分。

線索簿同時查保存與草稿，草稿覆蓋預覽並明示未按保存；篩選僅存當次分頁，刷新恢復，文字原稿不變。明示搜尋才換結果，IME組字不誤送，分頁與過期路由有守護；使用者文字編碼。索引與單字編輯頁按實際顯示文字記提示，同步七日與默寫cache；不把隱藏頁當曝光，不新增attempt。空白草稿不冒稱已保存，草稿仍走原編輯頁保存。

沒有新題庫、音檔、教材規則、帳號、後端或依賴。208卡、508筆順、10947音檔索引及K包668檔不變，schema3無遷移。舊首答、作品、自評、備份與離線包延續。
