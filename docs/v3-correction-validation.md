## 問題與修正

1. [變式題耗盡](https://github.com/linhercherng/japanese-learning-platform/pull/4#discussion_r4258217890)：相似字シ／ツ三題、K18 深化十八題，以及已有三個相似字到期項目的每日回想，第一題答錯後均有至少兩題間隔，卻沒有同概念／能力的未曝光變式，舊版仍插入原題。短 concept-practice 最多兩題，不能用它作為此回退的重現證據。
   修正為同時具備兩題間隔及未曝光變式才插入訂正，否則沿用 `deferred`，保留當題差異解析並在完成頁明示間隔不足或無新變式、留待後續複習。已有 schema 3 原題訂正輪次仍可匯入、接續，標示為「原題訂正」。
2. [訂正提示分支衝突](https://github.com/linhercherng/japanese-learning-platform/pull/4#discussion_r4258217953)：共同訂正待答快照分岔為「無提示提交」與「未提交但看提示」，兩份各自合法的備份合併後，舊版留下 `hinted:false` 答案與提示紀錄。
   修正為比照首次答案，雙向核對訂正答案與待答分支的提示；矛盾時拒絕整次合併。沒有實際使用者資料遺失證據；此次重現全部為合成資料。

不新增 schema 欄位、不清空進度、不改首次答案或跨日複習排程。沿用原合併拒絕與原子儲存流程。教材與其他文案不擴大修改。
