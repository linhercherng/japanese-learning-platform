# 第一版手機樣稿審閱

2026 年 10 月 12 日。依使用者確認的規劃，交付可點選手機樣稿，供確認學習與記憶體驗；正式功能開發待畫面確認。

## 畫面與設計選擇

暫用「日和 HIYORI」名稱，採暖白紙感、深綠與朱紅。首頁單一主任務，五十音一次五字；字形、筆順、手寫與生活句連成完整的小學習循環。

| 畫面 | 最重要的操作 | 記憶設計 |
| --- | --- | --- |
| 今日首頁 | 開始今天五個字 | 新字與先前項目分開，不用一次處理整份課綱 |
| 五十音 | 選字、看詞例、進筆順 | 字形、聲音位置與生活詞相互連結 |
| 筆順 | 分步與完整播放 | あ的三筆配合「一橫、一豎、繞一圈」提示 |
| 手寫 | 描寫與收起提示默寫 | 練習回想，自評而不假裝自動判分 |
| 生活課程 | 選一個能做的生活任務 | 從咖啡點餐等熟悉情境開始 |
| 點餐單課 | 對話、想一想、自己寫 | 先理解句型，再選句，最後換成自己的品項 |
| 相似字複習 | 對照シ／ツ，收起提示回想 | 找筆畫方向差異，再進行回想示例 |

## 範圍

導覽、卡片選擇、筆順動畫、畫面內塗寫、清除與復原、篩選、示範選句及換詞輸出，均只為樣稿操作。

沒有登入、資料儲存、後端、錄音、音檔或正式評量。所有數字是示範，字跡與輸入只留在記憶體，重新整理即清除。「播放」音檔按鈕明確顯示尚未接入素材。

## 已執行驗證

使用本機 Microsoft Edge 真實瀏覽器，以 Playwright 檢查：

- 六個主要畫面在 320、390、768、1024、1440 像素寬度沒有水平溢出。
- 平片假名切換、字卡、46 字完整表、分步及完整三筆動畫。
- 滑鼠筆劃、瀏覽器觸控輸入、描寫／默寫切換、示範對照、復原與清除。
- 課程篩選及未實作程度的明確狀態。
- 點餐答案解析、替換飲料、刷新後清除輸入與字跡。
- 相似字提示收合與回想回饋。
- 樣稿說明對話框、Escape 關閉與鍵盤焦點。
- 無使用 localStorage／sessionStorage，無瀏覽器執行錯誤與失敗的本機資源請求。

共 56 項檢查通過，JavaScript 語法及 Git 差異格式檢查通過。手機截圖來自 390 × 844 CSS 像素畫面；另附桌機配置。實際圖片見 [六頁總覽](../prototype/review-images/overview.png)。

這是桌機瀏覽器的尺寸與觸控模擬，尚未在真實 iPhone／Android 裝置驗收，也尚未測量學習保留率；「容易記憶」目前是設計目標，等待使用者實際試用。

## 審閱順序

1. 今日首頁 → 開始五個字 → 選あ → 看筆順 → 自己寫。
2. 寫一次 → 收起提示 → 再寫一次 → 對照與自評。
3. 回首頁 → 相似字複習 → 收起提示回想。
4. 生活課程 → 點咖啡 → 對話 → 想一想 → 換成自己的飲料。

優先確認資訊是否清楚、份量是否合適、按鈕與手寫區是否舒適，以及是否願意繼續下一個小任務。樣稿名稱、顏色與文字均可在此階段修改。
