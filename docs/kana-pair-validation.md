## 根因與修正

基本字記憶卡原先以 `reading` 找第一個另一套字形；「お／を」與「オ／ヲ」的讀音相同，因此「を」配到「オ」、「ヲ」配到「お」。此結果同時用於記憶卡的 partner／回想文字與 `km-h-3092-pair`、`km-k-30f2-pair` 的答案選項。

改以既有 `toHira` 字形轉換比對，與進階假名採用相同規則：`を ↔ ヲ`、`お ↔ オ`。沒有改讀音、音檔、字卡 ID、題目 ID、schema 或複習規則。

修正前完整 740 題與 208 卡的合成教材快照比對結果：只有兩道上述配對題的 `options` 改變，以及兩張 `h-3092`／`k-30f2` 記憶卡的 `partnerId`／`recall` 改變。其餘全部內容與 740 個 ID 相同。兩題仍以 index 0 為正解，沿用原有干擾項生成規則。

歷史答案、提示、對錯及排程保留，不追溯重評，也不清空或重建資料。舊記錄的存檔相容性與教材答案修正分開驗證。
