# 日和網站第四版規劃：從做題，走向記得住與用得出來

日期：2026-10-14；本輪交付N2教材與下列改版規劃。規劃功能尚未實作，須先確認手機流程／樣稿再逐批開發。

## 目標與現況

目標是讓使用者知道今天學什麼、能分清相似內容、隔天仍能回想，最後能在生活或職場運用。豐富度應來自可用教材、不同情境與有效回饋，而非首頁堆更多入口。

既有：208假名記憶卡／740加練題、筆順與默寫、生活課與情境、N5～N3主課／模擬、詞卡收藏／搜尋、錄音回放、5／15／30分鐘每日安排、弱項與到期複習、12個深化單元、作品／修訂、週回顧、個人備份及可選PWA離線包。本輪N2再補主課、20情境、詞彙、漢字、回想及兩套自編模擬。上述既有功能不列成第四版的全新功能。

## 新的手機導覽

保留五個底部入口，避免讓使用者重新學導航。

|頁面|改版後主要內容|首屏最重要的操作|
|---|---|---|
|今日|程度／目標、接續活動、到期弱項、今日小任務|一個「開始今天」與一個「接續」|
|學習|五十音、N5～N2主線、生活任務、先修關係|找到適合的一課，看到已學及待補內容|
|練習|弱項回想、文法對比、漢字、閱讀、聽力、角色任務|按能力選短練，預設小份量|
|檢定|診斷、題型解說、分區練習、兩卷／級與結果補強|清楚分自編練習與正式JLPT規則|
|我的|筆記、收藏、作品、錄音、週回顧、備份、離線／同步|找到自己的內容與資料保存狀態|

閱讀頁先呈現文章與一個任務，詞卡按需展開；聽力頁先給情境與播放，不預先露出逐字稿。文法對比用兩句與一個差異點起步，詳細接續再展開。學習頁避免卡片內再套多層卡片。

## 日常循環

5分鐘：2個到期弱項＋1個新例句＋遮提示回想。15分鐘：弱項→新概念→新場景→一句輸出。30分鐘：兩段短循環，第二段使用不同材料，最後自查。份量為建議，學習者可調整，不承諾固定天數學會。

N2特別增加：辨認作者主張、找限定條件、比較兩份資料、聽完多人的偏好再決定行動、把禮貌表現與職場責任分清。日常寫作／發音仍是獨立延伸，不列入JLPT官方分數。

## 交付批次與確認點

1. **第四版A：教材可信與銜接。** 審校流程、N3→N2診斷、12組文法對比、40組漢字記憶。先確認「診斷結果、文法對比、漢字記憶」三個手機畫面樣稿，再實作。
2. **第四版B：生活運用。** 24篇閱讀、30段跟讀、6個分支任務與個人筆記。先試讀／試聽各一個完整循環，確認可理解與可記憶，再擴篇數。
3. **第四版C：跨裝置。** 確認帳號／供應商／每月預算／資料處理方式，先測指定兩台裝置，再推出同步及輔助回饋。

建議先做A，再做B；雲端與AI功能等內容與流程成熟後再做。N1可排後續教材路線，先讓已加入N2的內容真正可學、可複習及可審校。

## 技術與成本依賴

- 本機閱讀、固定角色分支、對比題及筆記可延續靜態網站，不必立刻增加後端費用。
- 真人聲音、教師審校、錄音授權與持續教材維護需要人力及明確授權；預算另確認，不臆估單價。
- 帳號／雲端／AI需要供應商、配額、私有儲存、成本上限、刪除／匯出流程與使用者資料同意；目前不選定服務或建立付費資源。
- 素材包按級別／能力可選下載，顯示大小與已下載狀態；不預設下載所有級別。
- 若新增個人筆記或同步欄位，先設schema遷移與備份，保留V1～V3資料，不從空白狀態重來。

## 驗收門檻

每批至少完成一個可用的學習循環，再擴內容。需驗收320／390px排版、單手觸控、鍵盤／讀屏、提示與首答、離開重整、錯題回到到期複習、作品與備份、音檔／授權、離線包，以及部署後正式URL。實體iOS／Android、真人聽音與教師審校各自列證據，不能以桌機尺寸或單元測試代替。
